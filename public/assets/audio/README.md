# 百味录 · 轻配乐与交互音效

2026-11-10。本项目原创的合成旋律与音色草稿，不是实录乐器，没有采用外部旋律、录音或采样。生成程序为 [generate-soundscape.py](../../../scripts/generate-soundscape.py)，开发期使用 NumPy 合成 PCM；正常运行不依赖 Python 或 NumPy。

| 文件 | 用途 |
| --- | --- |
| music-home.wav | 老宅、终章与次晨；稀疏的暖音和缓慢低声部 |
| music-day.wav | 陈家与琴记；略亮的短句，保留阅读所需的空隙 |
| music-night.wav | 夜饭小馆；更低、更疏的晚间主题 |
| sfx-paper.wav | 翻书、信纸、照片与纸本内容切换 |
| sfx-wood.wav | 木制按钮与轻触 |
| sfx-cup.wav | 杯碟和碗具的轻碰 |
| sfx-door.wav | 场景通路 |

三段配乐各 40 秒，首尾淡入淡出，切换章节约 1.3 秒交叉淡化；同一章换房间不重启。首次点按或按回车进入游戏后开始播放，切回首页、离开标签页或静音时停止。音乐与音效分别调节，偏好保存在设置，均不进入剧情存档。点击对白正文和逐字显字没有连续提示音。

音效设有短间隔限制，避免快点时堆叠。原环境雨声占位素材仍保存在历史资源中，正式场景改用本组配乐。后续可替换为录制版本，替换时沿用现有资源 ID 和交互事件，不改剧情规则。
