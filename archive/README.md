# 历史工程

此目录的历史项目和原始压缩包保留在本地，Git 仓库只收录本说明。正式工程可以独立安装和构建。

- `prototype/`：最初的视觉、粒子与共享互动探索。
- `game-lab/`：此前的框架与资源形式小样。

这些项目保留用于追溯与素材参考。正式工程、运行命令和最新约束见 [根目录 README](../README.md)。旧稿中的功能范围、风格、人物与开发天数不自动沿用。

本地依赖从 game-lab 移至根目录，原源码与成品保留。查看旧 game-lab 的成品仍可运行其 START.bat；单独开发旧工程时可在旧目录重新执行 npm ci。
