# 图鉴与随身物品的 3D 查看

2026-11-10。

图鉴取消图片下方的旋转滑条，点图片拿起物件；随身物品整张栏目可点。两处共用同一查看器，仍保留原有收集条件、道具数量和调查奖励。查看、旋转、缩放及关闭均为临时表现，不修改剧情与存档。

## 参考与资产来源

只参考 `E:/Projects/HTML-Projects/Embers-and-Echoes/photo-viewer.js`、`envelope-viewer.js` 的 Three.js 独立网格、指针捕获、方向键、复位、从点击位置放大与反向收回、退出释放资源的做法。没有引入该工程剧情、界面、模型或图片。

本工程 `src/presentation/inspection-models.ts` 以程序化网格建立十类物件：白线轴、购物单、相框、旧书、家信、日历、杯碟、手机、钥匙、保温袋。旧书由图鉴与背包共用，所以覆盖 11 个条目。都是实际几何体，非旋转二维精灵。当前为程序化美术初版，后续可继续细化造型、磨损与材质。

木纹、纤维纸面和少量印字由浏览器 Canvas 生成，来源为本工程代码，没有新增第三方资产。相框照片从本项目现有 `public/assets/morning/props-v1.png` 的 `prop-photo` 区域校正取得，保留原人物形象；外框、背板和支撑脚独立建模。未覆盖原图，也没有新增外部运行时资源；照片纹理仍从 public 副本读取。

稳定 ID 到模型类型的映射集中在 `src/content/object-models.ts`；`tests/object-models.test.ts` 要求现有全部图鉴与道具都有模型，防止新增条目后点击进入空界面。

## 交互与过渡

拖动或单指滑动转向，方向键转动；滚轮或加减按钮缩放；可翻到另一面、摆正。进入时从原图或栏目中心放大，文字稍后渐入；放回、Esc、右上关闭都会先执行返回动画，并恢复原入口焦点。图鉴选中页和滚动位置保留。

查看期间底层条目设为 inert，避免 Tab 穿透。退出释放指针事件、尺寸监听、动画、几何体、材质、纹理及 WebGL 上下文；异步导入完成前退出不会再创建舞台。支持游戏设置与系统的减少动画偏好。WebGL 不可用会显示说明，保留返回入口。

## 验证

类型、内容检查与生产构建通过；180 项自动测试通过。构建仍有大于 500 kB 的分块体积提示，3D 舞台按需导入。

本机 Edge（Playwright，保持 Chromium 沙箱）实际浏览器验证：1280×800 与 390×844 各逐一打开 8 个图鉴条目和 3 个随身物品；拖动、方向键、翻面、摆正、缩放、返回焦点、Esc 分层返回、入场中断、右上关闭及存档不变。另检查 WebGL 不可用时的提示与返回。截图位于 `docs/art/previews/object-viewer/`。触屏与减少动画另用 390×640 验证；浏览器仿真不替代真机性能验收。

## 信件与手机第二版

按用户对原图片的反馈，重做两件物品，造型集中在 `src/presentation/personal-object-models.ts`。

- 信件依据现有 `public/assets/arrival/letter-flat-v5.png`：黄褐色旧信封、薄纸边、独立侧折与三角封口，右上露出浅蓝灰车票。去掉外表的家信正文与粗十字折线。纸纤维、票面细线由代码生成，保留当前原图的无正文外观，不增加虚构票号。
- 手机依据现有 `public/assets/arrival/phone-flat-v4.png`：薄圆角机身、低饱和金属边、独立按键与底部接口。去掉纸色备忘录屏幕，将原图的深色玻璃、窗格树影和前摄孔按四角校正映射到独立屏幕网格。外壳与背面保持实体厚度，可以正常转动检查。圆角轮廓与厚度分别控制，避免薄机身被做成硬直角。

本轮没有覆盖原素材，也没有新增外部图片。手机贴图直接读取 public 中的原图片；纸张与金属磨损仍为本工程程序化材质。类型检查与生产构建通过；Edge 的 1280×800、390×844 实测验证原图纹理加载、两面造型、翻面与返回焦点，无页面运行错误。第二版截图见 `docs/art/previews/personal-objects-v2/`。

## 第三版：遮挡修复与纯玻璃屏幕

用户要求移除手机屏幕图片；第三版优先于上面的第二版贴图方案。手机不再加载原图，也不使用窗格／树影图像。屏幕改为深色物理玻璃材质，前摄孔独立建模；使用 Canvas 生成柔光环境，经 PMREM 提供随转向变化的反光。退出时同步释放环境渲染目标。

信封原先的车票位于侧折纸层前面，导致右上三角区域露票。调整为信纸、车票、左右侧折、底折、封口依次叠放；车票面深度小于侧折，封口与侧折上沿齐平。信封只在顶部保留车票的实际露出部分。

类型检查与构建通过，桌面与窄屏浏览器复核两件物品的正面、斜角、背面与返回操作。第三版截图位于 `docs/art/previews/personal-objects-v3/`。
