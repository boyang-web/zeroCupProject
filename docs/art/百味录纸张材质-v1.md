# 百味录纸张材质 v1

2026-11-07。使用内置 `image_gen` 生成一张不含文字和装饰的书写纸材质，未使用 CLI。文字、食谱插图、桂花和 UI 控件分别渲染。

## 保存与登记

- 项目文件：[paper-fibers-v1.png](../../public/assets/journal/paper-fibers-v1.png)，资源键 `journal-paper`，已复制到 `public` 后引用，阶段稿已接入运行画面。
- 原稿保留在 `C:/Users/dell/.codex/generated_images/01a1aff8-d9f8-7ba0-8ee7-2339168267aa/exec-aa22db90-25a8-475b-8a9e-5918e1300cee.png`。
- PNG 为不透明纸张色片，未包含字体、线条、边框和花饰；原文件与项目副本一致，没有程序重绘或去背景。
- 原 `ui-book` 图集与旧书资产保留。本轮书本改用独立的布面封皮、纸叶、页缘、书脊阴影和装订线表现，其他木制面板沿用现有控件。

纸面按较小的材质尺寸平铺，左右页错开纹理位置，避免把大块纸纹拉成木纹。叠页厚度、书脊暗部和页角薄边由 CSS 构成；翻页仍由 GSAP 驱动，翻动的纸叶使用同一纸张材质。书内字体和独立桂花保持原有比例。食谱增加内容数据里的 `note` 页边小字，不把它画进贴图。

实际页面：[桌面食谱](previews/journal-paper-desktop-v1.png)、[陈家食谱](previews/journal-chen-page-v1.png)、[人生记录](previews/journal-life-page-v1.png)、[窄屏纸页](previews/journal-paper-mobile-v1.png)、[窄屏页边小字](previews/journal-paper-mobile-notes-v1.png)。阅读与回访范围见[纸本与叙事扩写](../planning/百味录纸本与叙事扩写.md)。
