## 此前确立的框架与创作起点

- 归乡人受祖母委托补全《百味录》，通过情景对话、场景探索与关键物件小游戏展开故事。
- 总共五章：第一章交代背景；第二至四章走访三家小馆；第五章呈现多种结局。
- 三家小馆分别涉及家庭温情、现代经营与老店熟客、深夜夜归人的晚餐。主角自己的故事贯穿全程。
- 人物群像、碎片与跨场景信息、章节属性、道具、成就、存档和不可撤销选择，都是需要承接的设计方向。
- 沿用 Vue 3、TypeScript、Vite、Three.js、GSAP，先用粗糙文本和素材占位；旧素材可复用，正式源码重新组织。
- 最新讨论优先于旧剧本；开发原则仍是解耦、先定整体、先跑通再细化。

## 临时规则，不等于最终设计

- 祖母在占位序章中直接出现，只为验证对话流程，不因此锁定设定。
- 属性名、阈值和三种结局名称都是测试数据。
- 小游戏暂不要求正式美术或完整烹饪规则，优先验证打开、交互、完成、取消、保存与回馈。
- 当前允许读旧档改变另一条时间线；同一存档分支内不能重选已作决定。
- 回响目前只在当前存档保留，没有实现跨周目成就。
- 第五章当前按过程条件自动结算；以后若加入最终选择，可以增加独立对话和条件，但不应抹除三店结果。

## 建议讨论顺序

本轮顺序：环境与场景 → 完整人物设定 → 关系与共同时间线 → 从生活中产生的事件 → 五章明暗线 → 分支、结局与逐场景剧本。环境已有参考底稿，目前重点讨论主角与祖母、老街的关系。

此前的工程验证顺序是：试玩框架，检查操作与信息组织 → 用第一家店验证内容接口 → 扩展另外两店与贯穿线。它作为实现参考保留，不替代本轮的创作顺序。
