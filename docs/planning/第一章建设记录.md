# 第一章《归巷》建设记录

2026-11-05。依据用户授权，自行合理化剧情并提升第一章与 UI 的完成度。本记录描述当前可玩草案，不替代团队后续对整体故事的判断。

## 本章成立的因果

玩家暂称“小满”，离乡后习惯用“忙”推迟联系。这次收到祖母的信，昨晚回到家。开场放在第二天清晨，以一杯温茶和仍被记住的小习惯建立归乡感。

祖母仍在，近期视力下降，写小字费劲。她的《百味录》最初记做法，后来连着记下邻里的习惯、赊账和捎话。最后三家店只有旧记录，她想知道如今的变化，所以请小满亲自走访。选择小满，既因为字写得大，也因为希望这个熟悉又疏远的孩子再走进巷子。

这使“补书”成为具体、合理的委托，也让祖母有自己的愿望和幽默。小满没有被要求留下、接班或完成救世任务，只需认真观察、确认对方意愿，并回应自己的承诺。

## 本章体验

1. 推开院门，进入清晨小院。场景提供六处可交互物件或人物。
2. 与祖母交谈。寒暄后逐步了解旧书、三店和委托理由；可追问“记配方还是记人”“为什么是我”。
3. 看过合照后，可询问陈伯与童年记忆。中途退出对话后，会根据进度重新接话。
4. 接受委托：可选择“慢慢问，回来讲给你听”，或“先把三家的味道记下来”。记录态度，提供选择前存档，不立即判好坏。
5. 翻开桌上的旧书，亲手把三张走访书签放进清晨、午间、深夜的时段。点选可替代拖拽，错误可修正，也可按祖母标注整理。
6. 收好书页与备用钥匙，出门进入第二章。可选观察不构成主线通关条件。

主角承诺如何影响中后期，还需要在后续章节中兑现；当前只是保留了明确的过程事实，不声称整个主角线已经完成。

## UI与美术

- 新生成桂花小院与透明祖母人物；书、信封、茶杯、合照和日历的热点按原画实际位置设定。
- 以暖纸、墨绿、赭红印记为主，减少硬边框和大块深色面板。页眉使用自绘线性图标，五章进度保留清晰的当前位置。
- 标题页以家书和院门建立开场，直接进入可游玩的故事，不呈现开发术语。
- 场景占主要画面，任务、三个阶段目标和出门按钮收在画面下方，保留环境完整性。
- 对话改为贴近场景底部的纸面界面，桌面端有祖母立绘、动作描述、分段正文与清楚的选项。移动端优先保证文本与选项空间。
- 观察特写分别使用书封、信纸、照片背面和日历纸张的排版；收集记录与轻提示保持克制。
- 书签整理有选中、放置、替换、正确完成、辅助与取消状态。
- 保留键盘按钮、可见焦点、Esc 关闭、减少动画、静音及读档恢复。
