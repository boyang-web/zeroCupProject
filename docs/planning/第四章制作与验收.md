## 可玩流程

- 店门 22:40：听许叔说两份饭与十一点关门，向罗姐确认堂食要求；抹布可拖过桌面，也可点开擦桌。留餐纸条为可选细节。
- 灶边：经许叔允许，只读小梁那一条回信，取得 22:55、辣酱另放、筷子盒外和没回信就上车的信息。可选想起自己的饭团往事。
- 双单分装：选单，再核对容器、米饭、豆腐烧菜、辣酱与筷子，试扣空盒并选择保温套或已有保温袋。无倒计时，可改错、取消重试或请许叔逐单带做。只上罗姐的饭，小梁的留餐等回信再盛。
- 柜边：罗姐吃完送回空碗，转门灯赶车。选择回准话、提前取消或先等。结果对白结束后再写结果旗标与店记；锁门前听完许叔的话才开放离店。中途关闭与刷新会续接尚未完成的收尾。

人物姿态、碗的位置、饭盒移除与门灯开关均由内容条件驱动。罗姐吃饭变为坐姿，去柜边说完赶车后隐藏；饭盒交出／收起后不再摆回台面。所有新热点均用独立世界精灵，沿用悬停和键盘反馈、点选靠近、关闭回正；未添加圆形热点覆盖物件。

## 为后续整合保留的接口

| 记录 | 含义 |
| --- | --- |
| `night-played` | 双单分装核对完成；不表示交餐 |
| `night-reserve` / `night-cancel-sent` / `night-wait` | 已确认的互斥决定；`decisions.night` 保存选择 |
| `night-pickup` | 小梁实际取到饭 |
| `night-called-off` | 提前发出取消，没有交出饭；不推断已读或已上车 |
| `night-missed` | 没有回信，也无人来取；不推断小梁去处 |
| `night-ended` | 锁门前对白已完成，可以离店 |
| `night-record-pickup` / `night-record-cancelled` / `night-record-missed` | 对应公开店记，供手记和未来终章使用 |
| `night-private-liang` / `night-private-xu` | 本次实际听到并另折的私札；不写入公开食谱 |
| `night-riceball` | 小满可选的私下回忆；尚未告诉奶奶 |

保温袋仍在背包中，不在小游戏消耗，因此离店时可直接取回。后续终章若实现归还，再由独立内容动作处理。
