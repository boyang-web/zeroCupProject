# 祖孙与街坊对白复核

2026-11-09。用户认为第一章已较自然，但祖孙的口气仍偏硬，许久没见的至亲不够亲近；要求沿这一方向检查第二、三章。本轮先处理关系，再检查接话、行动和已知信息，保留现有生活对白、分支与玩法。

## 老宅：两个人都在照应对方

奶奶先问昨晚睡得好不好，想让小满多睡一会儿；看见衣袖夹在包里，顺手替他抽出来。小满也记得衣架在哪儿，愿意自己挂好，再回来陪她坐。行李、旧杯子和手机不再每次都引出一段纠正。

| 场面 | 这轮的实际来回 |
| --- | --- |
| 起床 | 奶奶问睡得好不好，小满问她什么时候起来；找衣架和收衣服顺着接下去，再问吃饭 |
| 怕被问工作 | 小满可以说还没想好，奶奶愿意让他多住几天，也直接说自己想跟他多待会儿；旧书仍是她真想继续记的事 |
| 喝茶 | 小满替她挪杯子，也劝她下回换新的；奶奶接下照顾，给他留着新杯，叫他一起坐 |
| 回家 | 直接迎他进来歇会儿，腾干的地方放书；不先问是不是落了东西，也不催着完成走访 |
| 手机 | 奶奶愿意听小满讲没写好的简介，小满也耐心教她删字。她想学会，是想平时也能快些给他回话 |

书、线轴、茶杯、家信和个人记录同步调整。吃过早饭、提前归还线轴、已经听过笔迹故事的版本继续保留。线轴的文字版本改为明确组合的回合，不再靠搜索一句旧台词来替换，后续改口气也不会使它重新掉到地上。

## 陈家：熟人帮忙，父女仍有各自的事

第二章以用户认可的[生活对白版原稿](../百味录_第二章_一笼早饭_对白重写v2_生活对白版.md)为底稿，原文件不改。保留早市插话、五只早饭、教室画、两张纸、试样安排与父女拌嘴。

陈伯仍忙，也坚持面团要亲自验；教小满时会留一小块面、一起洗手、托着再练，做错了就一块换回来。阿宁见到旧友会先让他坐、问行李和饭，也愿意把高兴和担心说给他听。小满主动搭手，关心她的报到与试讲，不一直替父女分析问题。

父女说开班车表时，陈伯承认该早点拿给女儿看，接着认真问她的教室；暂缓路线里，他也承认自己刚才话急，仍没有当场同意试三天。工作上的分歧与各自决定保留。

顺手修正了两处连续性：老周不再说自己吃掉了小满那只月亮包子；未实际搬凳时，护膝话题只邀请搭手，不提前演成陈伯已经坐下。坐姿版本跟实际搬凳的标记走。各路线回访继续区分三日试样、只看一盆与未谈定。

## 琴记：有熟悉感，也说清楚眼前的事

琴姐先认出小满，留地方、留筷子，忙时说明这几份怎么分工。阿川和他平等地认单、补算，不把帮手当成来受训的人。田姨与琴姐熟，但第一次请小满跑腿会说麻烦；半份、不葱、什么时候能吃仍要问明白，催面的事没有含混过去。

限两单试一周、先补传单、继续接单三种结果原样保留。限量会有人离开，只补备注仍需晚上算容量，继续接单仍要出去说明赶不上的时间。口气放缓不替角色抹去这些后果。

阿川算单时改谈尚待安排的装盒、认人，不再在出餐前说玩家刚跑过一趟。出餐后、尚未吃自己的面时，他仍叫小满去坐；三种结尾吃过以后，再找他会接“吃过了”。筷子的观察文字也跟这两个阶段分别显示。
