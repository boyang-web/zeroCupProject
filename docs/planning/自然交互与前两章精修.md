# 自然交互与前两章精修

2026-11-09。落实本轮连续反馈，覆盖前两章文字、全站公共界面与物件阅读。第二章仍以用户的[生活对白版原稿](../百味录_第二章_一笼早饭_对白重写v2_生活对白版.md)为语言基础，原文件保持不变。以下新增生活细节属于 Demo，不固定重策划中的职业、年龄或身体设定。

## 界面与教学

- 教学只指向当前物件，取消“试一下”代理按钮。展开时继续屏蔽其他物件的点选、拖动与键盘选择；收起可自由探索，镜头回正后再呈现下一步。
- 左上只留地点与时间。游戏内品牌框、中央章节轨迹、右下重复地点、物件提示模式及其设置入口均移除。
- 回家、回原行程、章内房间和下一章出发统一放在左右边缘中央。左下是相同木制正方形按钮：手头的事、百味录、随身物品、走访、菜单；按教学进度渐入。菜单只保留图鉴、拾零、存读档、设置和首页等内容。
- 白窗的标题、人物区、正文与留白都能补全／继续，空格和回车同样可用。末句只展开回答，需明确选答；拖选、按钮与窗口外点击不多推进一句。删除重复的全文与继续按钮。

## 物件与阅读

信封直接点实物展开，照片点实物翻面，茶杯、凳子和借袋等单一结果直接执行。借袋保留两条旧动作 ID 和同一个奖励键，界面不再把“有钥匙”与“开口借”当两个重复确认；真正不同的结果仍明确选择。已完成的一次性动作不再留一个禁用的完成按钮。

家信在信纸上完整呈现称呼、正文与落款，小满读信时的回想另放在旁边。手机显示没改完的个人简介，保留结束日期“至今”和半句“能够适应……”，不往简历里混入返程安排或虚构编辑时间。琴记显示自己的接单设置，许叔的手机显示订餐消息。没有给阅读物件再配一段点亮、展开、翻面的玩法解说。

《百味录》直接打开到可读书页，同一本书内有食谱与走访书签。翻页立即更新内容，纸页短动画不锁操作；落墨按段呈现，避免逐字创建大量 DOM。整理书签归位后自动结束，短暂等待中取消不会领奖。做早饭保留馅料、数量和分装校验，正确分装后一次端走，取消多出来的核对后继续和完成后“回去”。人物回应回到场景短暂呈现，不阻塞下一次操作。

对白正文与回答、物件叙述、信纸、手机、照片背面、书页正文与图鉴说明各有自己的滚动区。外层窗口、实物、书脊、插图和页签保持原位。较长的小游戏工作区在窗口内部滚动，不带动页面；带做对白也能单独滚动和点按补全。

## 文字与前后行动

第一章保留熟悉的祖孙口气，明确小满看见什么、想做什么，再接动作和奶奶回应。例如：

> 你看到一只白线轴从椅脚边滚了出来，线头拖在地上，还绕着椅脚打了个转。奶奶本想自己捡，手里的布还没放下，你已经先一步弯下腰，把线轴拾了起来。

> 在呀，就门口换了块招牌，灶间还跟从前一样。你到了喊他一声，他见了你呀准高兴。

旧照片围绕小满等开笼、护着漏馅包子的回忆展开；家信与手机补入他对返程、求职草稿和向熟人解释近况的迟疑。茶杯不再复述“已经在手边”，而写奶奶招呼他拿自己的杯子坐下。删掉“最后一行，比前面的字小一点”等没有独立叙事用途的尾句。

第二章的物件观察加入小满对阿宁买粉笔、陈伯私下记班车、父女各自着急的感受，避免看什么都立即劝和。正文同步修正阿宁已经吃过一口却又说始终未动、画仍在柜上却提前出现在碗底、老周早饭未出笼却说已经装袋，以及米酒原量未擦却说划掉等细节。三天试样、只看一盆与暂缓三种结果继续区分，阿宁照常报到，不凭阅读物件替双方作决定。

凳子的原文先写搬好、实际却要再确认，是画面误解的一处来源。现在点或拖就执行原 `move-stool`，陈伯换坐姿，原凳子入口消失；护膝话题中的选择同样明确是在替他搬凳。借袋后移除柜边物件，取走的早饭与收完的饭桌仍按既有阶段显隐。
