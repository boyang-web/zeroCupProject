# 第二章营业与生活布局

2026-11-07。沿用用户对第一章的要求：先考虑人在这里怎样营业、做事和生活，再摆放人物与物件。保留陈家三个场景、现有分支、小游戏和剧情进度，新构图不作为完整新剧本定稿。

## 三处空间各自做什么

| 场景 | 实际用途 | 物件与人物的位置 |
| --- | --- | --- |
| 店门口 | 等候、售卖、取餐、收银 | 长凳给客人等早饭；陈伯在柜台旁的工作位；留单夹在收银处；预留的两只菜包放取餐搁板；卖空的笼屉放售卖台一侧；小凳子收在长凳里侧，可挪到陈伯身边 |
| 灶间 | 备料、揉面、蒸制与入口收纳 | 擀面板平放揉面案，旁边有面粉桶和水碗；竹笼落在蒸炉锅圈上；备料表挂在墙板上；围裙挂入口干墙，保温袋挂干柜，护膝收在下方个人小格 |
| 后院 | 洗手、家用收纳、吃早饭 | 阿宁在水池旁擦手；报到信和孩子的画留在帆布包旁的干凳上；父女合照与班车账本在家用柜；饭桌留给碗筷、包子和两个人的茶，讨论时才把账本拿过来 |

前台敞门连接灶间，灶间的后门通向水池与后院。三张图保留同一铺子的绿木门、墙面、采光和相邻空间。通道与可走动的地面保持清楚，陈伯不站在售卖台面上，纸件也不占揉面和洗手的位置。

## 人物与物件随行动变化

- 挪凳后陈伯换为完整坐姿，人物和凳子保持接触；原来的空凳不再重复显示。
- 陈伯来后院时，前台不再同时留一位陈伯。父女各坐一张小凳，相向吃早饭，空座图层相应隐藏。
- 成功收束后的父女继续坐着，不在说完“坐下吃饭”的瞬间消失。行程推进到琴记以后再回访，陈伯才回到营业位置。延期分支中，陈伯回柜边，阿宁到干凳旁。
- 保温袋借走后，柜门上不留第二只；分餐后，取餐搁板上的预留包子不继续显示；蒸炉中的笼屉变为空笼。
- 倒茶前是两只空杯，倒茶后同一茶具组显示两杯茶。父女旧照片改为专用的两人合照，学校通知也使用近期白纸信件与孩子的画。
- 备料表、相框可翻看，报到信可展开，班车账本可翻页。账本有自己的封面与内容，不再套用“百味录”的名字或提供食谱入口。

这些表现使用既有旗标、物品数量和行程条件，不新增剧情存档字段。原有行动 ID、一次性奖励和三种结局继续沿用。

## 取景与退出

每个场景按工作位置配置多个取景，点选后先靠近目标再交互。关闭面板、按 Esc 或结束对话后，镜头自动恢复标准全景；连续面板切换结束后才回正。窄屏按目标在变换后的位置移动观察窗口，避免柜边目标被裁到屏幕外。

角色、物件和命中区域在同一世界画布中，界面控件独立显示。柜台与小饭桌的前景遮挡用于保持身体与家具关系。当前仍是分层图片与取景缩放，不代表完整透视相机、自由行走或物理模拟已完成。
