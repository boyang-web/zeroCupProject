# 第三章独立故事与空间布局

2026-11-07。按用户要求修正陈伯坐姿遮挡，并把第三章按前两章标准做成完整的独立故事。仍为五章，第三章保留三个场景与原有三种局部结果，不把本轮扩写视为尚在重策划的新剧本定稿。

## 这一章发生了什么

小满带着奶奶的书来问清汤面的做法，却先看见田姨守着一碗没动过的面。她要半份、不要葱，午休还得回对面的缝纫铺；琴姐认得她的习惯，忙着接新单时却没能把习惯传到单上。阿川想给姨妈的店补一些生意，也想在返乡后做成一件事，便总在来单时先答应时间。

玩家从窗桌、灶边和接单柜听完三人的话，发现堂食、外送与忌口没有落在同一条队列里。三张眼前的单必须放进两口锅的顺序中，田姨那份同时核对半份与无葱。阅读和探索不扣真实时间，等待由排出的顺序计算。

出餐后，田姨终于能吃上合适的一碗；阿川把算过的纸拿到店堂，琴姐腾出手谈明天。收束有三个方向：先按两单试行限量一周；先将堂食和特殊份量写清，饭后再算量；继续按原时间接单，必须先给等久的客人回话。三种结果都有自己的后续接话，仍能问清做法、吃面、留下记录并继续去夜间食堂。

这一章的明线完成于《百味录》里的一碗面：清汤与煮面分开，份量和忌口写清，葱花最后问过再撒。支线让玩家听到门帘修补的往事、阿川返乡的心思，也能把小满手机里的简历与他的话接上；这些不作为主线的强制前置。原有 21 个对白节点已扩写，新增 6 段支线和收束接话，共 27 节点。

## 三处空间

| 场景 | 用途 | 实际摆放 |
| --- | --- | --- |
| 店堂 | 坐下吃面、取餐、交谈 | 田姨连人带方凳坐窗桌外侧；碗杯在桌面；菜单在墙上；旧门帘在厨房门上；琴姐站出餐通道旁 |
| 面案 | 揉面、两锅煮制、传单、洁净出餐 | 擀面板平放揉面案；调味罐在金属落台；单子夹在干墙；筷子与给小满留的碗在门边出餐架 |
| 接单柜 | 收单、对照设置与旧记录 | 打印机和手机分占干柜，点单簿摊在中间；退单另夹墙板，不混回新单；窗外能看见田姨做活的铺子 |

三个场景共 17 处交互。阿川有柜边与店堂两个位置，按进度互斥显示，同一时间只有一个。收束时他站在琴姐左侧，避开右侧通路牌；进入后续行程再回访时，他回柜边。田姨在结果确定后回对面做活，窗边留下空碗、空杯与空凳。小满的面也会在吃过后换为空碗。

## 阅读、物件与镜头

全部对白与观察继续分段显字，读到最后一段才出现回答或行动。菜单、纸单、门帘可翻面，簿子可翻开，手机可点亮；手机显示琴记接单设置，按结局更新上限或备注，簿子使用“点单簿”封面。菜单字由本地字体独立绘制，图片与文字不相互拉伸。

每个工作位置配置取景。选中后先靠近，关闭物件或结束对话自动回全景；窄屏使用下方物件按钮并恢复原观察位置。木框教学先指向窗边的碗，排单界面使用同套纸面、木牌和字体，支持点选、原生拖动、移出与请琴姐指点。小游戏只返回完成或取消，由规则层发一次奖励。

进入第二章即开放的回奶奶家功能在本章继续可用，回访读档保留原房间、决定和设置。没有新增剧情存档字段，内容 v4／状态 v3 与原有奖励 ID 保持兼容。
