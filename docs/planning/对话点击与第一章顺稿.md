# 对话点击与第一章顺稿

2026-11-08。用户反馈对白变多后操作不顺，要求点对话框任意位置补全当前句或进入下一句；第一章仍有接话和指代问题，第二章新增物件有重叠。本轮分别修输入、完整会话和场景布置，原有分支及存档继续保留。

## 对话怎么点

对白窗口内的文字、标题、人物区域和留白共用一次阅读操作。正在显字时补全当前回合，已显示完整时进入下一回合；不用等待“继续”按钮的淡入。最后一句后留在回答处，再点留白可以立即显示全部回答，仍需点选具体回答才会产生剧情行动。关闭、显示本段、继续和回答按钮各自处理一次，不随事件冒泡多走一句。

拖动选字、滚动以及点窗口外不推进。旧的按钮与键盘选择继续保留。物件翻看、小游戏、书页和菜单没有套用对白窗口的点按操作。

实现位于 `Modal.vue`、`DialogueView.vue` 与 `useReadingSequence.ts`。点击只改变当前阅读游标；窗口结束前不会替玩家选回答，游标和快读状态也不进入存档。

## 第一章实际修改

21 个节点重新按完整会话检查，选项文字、重复返回和几处已听过的版本一起处理：

- 先问早饭，接话区分吃过一点和没吃。手动归还过的线轴不再从椅脚滚出来，两种情况可以同时成立。
- 奶奶从旧书里想补的做法说起，交代为什么这些年没再去问；小满问具体问什么、怕被问工作，都有针对的回应。返回委托时只接着问，不再用含糊的“照你问清的来”重开一段。
- 找钥匙、保温袋的借用许可、三张长书签和留在家里的购物便条分别交代，避免玩家不知道前一句指的是哪样东西。
- 手机话题直接接“个人简介改不完”，再转到奶奶自己的输入框；不再凭空问“你刚才看见我手机了”。两只手机、旧书和纸页的拿放补上动作，不从低柜突然出现在人物手里。
- 煮糊米酒、两种笔迹和认错院门各自说完整。已听过米酒故事再看便条时，会认出那行字；只听过认门的故事，书内仍只写认门。
- 合照、书页观察、钥匙与袋子说明、线轴收藏及米酒页边笔记同步检查，不把可选对话还没发生的内容预先写成既成事实。

最新对白见[第一章阅读稿](../百味录_第一章_归巷_生活对白版.md)，包含全部可选话题。物件、书内文字和版本仍由 `npm run export:story` 更新到[全站文本](../百味录全站剧情文本.md)。这些仍是当前 Demo，不据此固定主角职业、失业原因或奶奶的身体情况。
