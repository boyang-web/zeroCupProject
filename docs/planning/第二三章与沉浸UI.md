2026-11-07 补充：第二章已按[营业与生活布局](第二章营业与生活布局.md)重构三处环境与独立人物，取景和退出自动回正与第一章一致。挪凳表现改为人物真实坐下；剧情分支和行动 ID 保留。以下记录的是原 Demo 的内容组织，不作为后续新剧本定稿。

## 第二章：一笼早饭

场景为店门口、灶间、后院，共17处交互、23个对话节点。陈伯仍按父女两个人的作息备料，阿宁下周要去城南小学任教。她改过备料表，父亲则在账本末页抄了班车时间。玩家从两人的只言片语和两张纸里拼出分歧。

必须经历打照面、听阿宁说工作、配好早餐并看火，再将陈伯叫到后院。旧照片、护膝、案板身高线、老客纸条和保温袋提供补充。把凳子挪近后，场景里的凳子也会换位置。

三种局部收束：把两张纸拿到一起，先试三天；先让父女坐下来吃饭，往后的安排留给他们继续商量；暂且照旧，把没说完的话和原来的订面量一起留下。最后一种记为局部任务未完成，但旅程可以继续。

小游戏先按馅与数量分好三个人的早餐，再观察蒸汽揭盖。配错可改，火候不合适可重来，也可请陈伯带着做。切到别的标签页会停火，退出清理计时器；只有完成时才由规则层记奖。

## 第三章：窗边那一桌

场景为店堂、面案、柜边，共15处交互、21个对话节点。琴姐记得老客的半份和不要葱，阿川接入线上订单时还没把这些习惯写进去；新的订单统一要求十五分钟，厨房却仍只有两口锅。田姨的午休和对街的缝纫活让等待有了具体分量。

玩家需先听过三个人，再安排三张小票。两口锅分别按队列累计时间，田姨那一份还要核对半份和不要葱。没有实时倒计时，探索时的叙事时间不自动流逝；难点是理解限制并安排顺序。

三种局部收束：算清容量后试行限量接单；先将堂食与特殊份量补进单据，饭后继续算量；继续照统一时间接单，最终不得不联系超时的客人。选择不会把现代经营本身判成错误，锅数、工序、承诺和人工记录都参与结果。

阿川返乡找工作的经历可与第一章日历上“别问工作”产生补记。新增半份无葱面资产，出餐后场景里的面碗与观察文字一同改变，未看过的旧错单不会在此时补发为已知线索。

## 独立物件

第一至三章的互动人物与道具不再由圆形图标代替。每个对象登记资产、尺寸、位置、层级和可见条件。鼠标移上或键盘聚焦时，物件本身上浮、变亮，名称临时出现。提示模式只略微描边，不把整幅画重新挂满标签。

生成图集按透明边界登记为独立精灵；背景只承担环境与家具。原PNG保留，脚本只读取像素范围并输出区域数据，不改图。物件状态可改变位置或图像：挪凳、递茶、开笼、上正确的面。物件拿到近处观察时，也使用同一份资产。

章与场景是两级概念。仍为五章，第二、三章各有三个地点；换场景只走配置中的通路，不通过修改章节数量实现。

## 全屏与木制UI

默认占满浏览器视口，底图和物件使用同一个画布坐标；画幅不足时整体裁切，避免只裁背景使物件错位。触屏窄屏允许横向观察。右上角可请求浏览器真正全屏，必须由玩家点击启用。

页眉、章签、去处牌子和收起的任务牌分布在边角。左下任务说明可展开；未展开时尽量不盖住面案。对话、手记、存档和设置使用新生成的木纹雕花与旧纸素材。

成套UI有12个部件，含对话框、书页框、菜单框、按钮常态／高亮／选中态、页签、木梁、关闭底座、切换底座、通知牌和滑轨。面板通过九宫格切片保留角部；文字、图标、焦点和按钮语义保留在HTML中。控件使用同一组贴图变量，世界物件不套木按钮皮肤。

## 状态与存档

状态格式升为v2，内容版本为v3。记录当前场景、已到场景、任务、线索、道具、关键决定和对话游标。游戏命令只处理当前场景的物件；隔着场景提交、尚未听清要求就提交小游戏，都会被拒绝。

上轮内容v2存档可显式迁移。第一章继续原进度；停在旧占位第二或第三章时，保留此前章节并从重写后的本章入口重读。未读取的档位不会被修改，不兼容档案不静默重置。

## 验证范围

类型、内容与资产引用、35项规则／存档／玩法测试及正式构建通过。测试覆盖18种三店结果组合、两章三种局部收束、场景限制、奖励去重、旧档迁移、分餐、蒸汽区间和两锅排单。

浏览器连接仍因环境元数据缺失失败，未绕过此前的启动限制。实际全屏排版、人物合成、SVG贴图与滤镜、焦点、触屏和声音还需真实浏览器检查。本文不把构建通过视为审美验收。
