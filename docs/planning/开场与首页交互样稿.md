# 开场与首页交互样稿

2026-11-10。本轮用于讨论网页比赛展示方向，覆盖首页、叙事引子、进入第一章前的转场。不是新剧情定稿。

首页：复用已登记的 title-homecoming 底图，新增代码绘制的立体布面书封、书签、桂花粒子、指针视差、文字显现及光影。点击书或“推门 · 回家”进入引子；存档、继续、设置沿用现有入口。

引子：三个手动推进场面。第一幕用空白日程、待写简历表达失业近况；第二幕用奶奶的日常消息与小满的回复建立至亲关系；第三幕用象征车票和未写完的简历连接回乡。年龄、职业与离职原因均不固定。手机消息、纸箱、车票及具体措辞属于本轮试写，等待用户评审；没有修改正式章节稿。

开场只管理展示状态，不保存剧情标记、不自行发奖。结束或跳过交还原有开始流程；有旧进度时仍需原有重开确认。支持随时跳过、回看各幕、触屏点按、键盘 Tab/Enter 与减少动画。Chrome/Edge 独立预览目录中的旧存档仍可继续。

技术：Vue 场景切换、CSS 透视书封、合成层位移、响应式布局；复用现有美术，不新增生成图片，不增加运行依赖。本轮尚未实现真实纸页形变、空间音频或 WebGL 景深。

## 交互修订

按用户反馈：无存档首次进入强制物件引子，不提供跳过与分幕跳转。手机需向左滑开，再滑动推进消息；车票向左拖出进入第一章。已有存档直接呈现首页，拖开书封继续原有存档；保留存档管理与重读引子入口。删去宣传短句、物件旁解释与主操作按钮。操作以微动方向暗示，支持指针捕获、触屏拖动和键盘 Enter/Space 等效操作。新增布面纹理、书页切口、翻封与手势实时跟随、手机玻璃反光及背景聚焦。尚未更换底图美术。
