# 渐进阅读与窗口教学

2026-11-07。按用户本轮要求调整：叙事文字逐步显示，选项随后出现；前两章略补文案；教程改为明确的窗口、文字和箭头，保持现有木制 UI。

## 2026-11-08：第一章聚焦与渐进界面

同日后续反馈优先：教学窗再精简为标题、一句操作和一个行动，正文即时完整显示，不让短操作提示再占一个快读按钮。重复的底部说明与长段提前讲解已取消，窗口收窄到 312 像素；手机拿起后，由实物自己的提示再教点屏幕。故事的渐进阅读继续保留，具体扩写见[全篇口语改稿与短教学](全篇口语改稿与短教学.md)。

最新反馈要求教学更专注、衔接更顺，并移除包围演示物件的黄框。第一章的手机、奶奶、旧书和书签四步改为聚焦教学；出门一步恢复自由探索。

- 聚焦时只有当前目标接受场景点击、拖动与键盘选择；窄屏物件栏只保留当前入口。世界按钮、拖动回调和应用交互入口同时检查限制，面板和镜头移动中也不能切去其他对象。菜单继续提供设置入口。
- 开场只保留场景、教学窗与简化菜单。读过旧书并放下后，再渐入《百味录》入口；整理完成后，章节进度、任务、物件提示与保存状态分批出现。发现提示等到教学让出注意力时再显示。
- 黄框和硬边矩形开孔取消，改用没有边线的柔和明暗过渡、物件轻微提亮与细箭头。沿用原木框、纸面、独立字体与按钮，没有更换或拉伸素材。
- 镜头先回到标准位置，下一步教学再出现。连续观察、翻书和书签面板期间保留当前步骤与取景；没有重复弹入教学窗，也不提前露出新解锁的场景控件。
- 教学可收起，自由观察后继续；取消同一步的交互仍保留收起状态，进入下一步重新展开。减少动画立即呈现文字与行动，保留快读。收起、阅读与聚焦状态仅存在于当前页面，不写进剧情存档；开发者模式不受聚焦限制。

内容用可选 `GuideStep.focus` 与 `chrome` 配置，规则层仍只依据原有条件推进。`useTutorialPresentation` 管理当前已呈现的步骤与暂时收起，场景相机的返回过程也纳入教学暂停范围。内容 v5、状态 v3 不变。

## 阅读顺序

- 对白先显示人物动作，再逐字显示说话内容；正文读完后，回答按间隔依次出现。
- 物件面板先显出观察文字，再补充题注、书页目录等内容，之后开放行动、小游戏和食谱入口。物件翻面、信纸展开、手机点亮后，物件上的字另行逐行显示。操作反馈也会逐字出现。
- 正常显字间隔约 26 毫秒，逗号类停顿已缩为 45 毫秒，句末或段落交接缩为 120 毫秒；正文结束后约 180 毫秒开放第一项，后续各项间隔 150 毫秒。教学的一句操作提示即时呈现。
- 点正文或“显示全文”可以直接读完当前文字，不会自动选择回答或执行行动。物件上的字有独立的全文按钮。
- 未显出的字保留排版空间，避免段落不断跳动。未开放的选项隐藏、禁用并移出焦点与辅助阅读顺序。辅助阅读提供一次完整的文本，不逐字反复播报。
- “减少动画”开启时，立即展示文字与选项；关闭物件、切换对白或离开场景会取消相应阅读计时。阅读游标只在当前界面中，不进入剧情存档。

第一章与第二章补充了 19 处既有观察和对白，增加物件使用痕迹、具体动作与人物口气，没有新增角色经历、分支或奖励。正文分别在桌面与窄屏上略增字号；沿用原字体，并重新生成字体子集以覆盖新增用字。

## 教学窗与箭头

复用已有 `ui-menu` 木框九宫格、纸面、青绿按钮与本地字体。箭头用原生 SVG 绘制，颜色与木纹、纸面一致，没有生成或拉伸新 UI 图。

教学窗出现在目标附近，连线指向物件，目标区域保留亮度；物件、角色和场景仍共用同一世界画布。窗口位置避开目标及屏幕边界，随缩放、滚动和窗口大小重新计算。角色只轻微提亮，不离开椅子上浮。

“现在试试”与直接点击目标经过同一原有交互入口，镜头先靠近再执行交互。第一章聚焦步骤须先收起教学，才能选择其他物件；其他章节的提示与出门步骤允许直接探索。点“继续教学”重新展开，收起不改剧情旗标或存档。

窄屏中目标不在当前观察窗口时，箭头改指向下方对应物件按钮，并把该按钮滚动到可见处，不指向屏幕外。物件面板内还保留同风格的短说明与向上箭头，明确提示点屏幕、翻封面、展开信纸或翻面。

第一章依次教学：手机观察 → 与奶奶交谈 → 翻旧书 → 整理走访书签 → 出门。若中途关闭委托的最后说明，继续指向奶奶，听完再进入翻书步骤。第二章收束后，新增系统的教学箭头指向菜单，让玩家找到回访入口。教学只由既有进度条件推进，不另建一套故事状态。
