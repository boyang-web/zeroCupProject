# 叙事调研与前三章改稿

2026-11-07。回应“文字质量低”的反馈，先查创作者资料，再改现有可玩稿。这里的结论用于当前 Demo；主角年龄、原职业、失业原因、奶奶的具体身体情况等仍待讨论。

## 调研依据

参照的是叙事方法与文本组织，不照搬作品的句子、口癖或世界观。以下前三列概括公开资料，最后一列是本项目的创作判断。

| 作品与资料 | 能确认的创作方法 | 适用边界 | 在《百味录》中的用法 |
| --- | --- | --- | --- |
| 《Heaven’s Vault》：Jon Ingold 的[调查型谈话设计文章](https://www.gamedeveloper.com/design/designing-investigate-conversations) | 穷尽话题的菜单容易让玩家只关心信息是否收齐；谈话需要人物意图、语境和知识变化 | 不意味着取消所有调查选项 | 不让陈伯见面就解释完整家庭矛盾。先接待、忙活、岔开，再由两张纸引出当面追问 |
| 《80 Days》：Meg Jayanth 的[GDC 演讲公开概要](https://www.gdcvault.com/play/1023062/Forget-Protagonists-Writing-NPCs-with) | 配角有自己的动机、主动性，也能限制主角的行动 | 本轮阅读的是公开概要，未据此声称看过完整演讲 | 阿宁照常去报到；田姨要吃饭、缝衣、收工钱；小满不能替他们决定人生 |
| 《林中之夜》：Scott Benson 的[创作访谈](https://cartridgelit.com/2018/05/15/interview-scott-benson/) | 分段文本形成停顿与节奏；选项可以探索一个已有性格的主角，不必每次都是重大道德决策 | 不移植网络笑话或角色口癖 | 小满会接不上“请几天假”，会借锅响岔过去，也会说错。长场面改成来回接话，段长随当下反应变化 |
| 《肯塔基零号公路》：Jake Elliott 的[设计访谈](https://www.gamedeveloper.com/design/-taking-genre-conventions-as-your-starting-point-is-kinda-boring-) | 设计从场景和语调出发；部分选择用于表达人物，而非只负责分出输赢 | 当前三店仍有会改变结果的决定，不能把真实分支伪装成纯表达 | 保留试行、先吃饭、暂缓等结果，同时让回话、沉默、等对方开口成为可信的场面动作 |
| 汪曾祺《端午的鸭蛋》[原文节选](https://www.chinawriter.com.cn/n1/2018/1127/c405084-30428152.html) | 食物通过挑选、动手、吃法和明确的个人偏好进入叙述；口语里有讲述者自己的判断 | 不复制标志性句子，不把高邮习俗安到长明巷 | 写包子分哪只、面能吃多少、杯口从哪边喝；不见到一种食物就插入一段笼统的童年与乡愁 |

## 对旧稿的判断

此前增加了字数，但许多段落仍在替剧情解释：每件物品先写材质，再写童年，最后暗示温情；每个人都能长篇分析自己的心事；小满只要听完，就能提出稳妥方案。人物的分歧被讲明白得太早，玩家后来翻物件，常只是再读一次答案。

这次先改场面：谁要办什么、哪句话没被接住、双方知道的事情哪里不一样。句子跟着这些变化走。允许人物好心办错事、误会对方、嘴硬、讲到一半改口；温暖仍在，但不要求每次交谈都以体谅与感悟收尾。

## 已实施的改造

### 第一章：奶奶也在过自己的这一天

她在补布、找钥匙、准备晾东西，不一直坐着等待玩家触发主题。问错车次后自己改口；真想续书，也嫌空白拖得太久。煮糊米酒的往事，通过两种笔迹和一个被漏念的“再”字展开，不在结尾代替玩家解释传承。

信封内给出完整家信。简历停在未完成的自我介绍，保留主角的不自在，不为他填入尚未确定的原职业和离职原因。

### 第二章：两张纸改变谈话

陈伯怕送来的面团不合格、错过取餐时间；阿宁以为父亲不肯看自己的安排，却在账本里看见改过的班车站名。他们并非各讲一段“舍不得”，而是在桌边对照、质疑、回答。

“先验再收”“谁搬面”“上课不接电话”由父女自己谈。普通吃饭路线同样有内容：陈伯想擦桌岔话，阿宁点破，他放下抹布。暂缓路线里，阿宁仍照常去学校，不用牺牲自己的工作证明亲情。

案板的物理逻辑也同步纠正：分剂子的准线留在案面，不再把平放的揉面板当量身高的门框。原线索 ID 保留，正文和簿内记录改成相符的内容。

### 第三章：错碗不是一个人的错误

琴姐承认，先把手机菜单填成整碗，是她与阿川共同作的决定；后来一直没补半份。田姨可以当面说“我这回也是跟柜边说的”，不必先解释自己理解大家辛苦。阿川担心少接生意，也担心回来以后又把事情做坏。

小满与阿川的选支谈到两份没改完的简历，小满不再负责给他讲疗愈道理。三种经营收束各自承担后果：限量会真的放走一单；只改堂食仍有待算的接单量；继续承诺则得出去解释超时。

### 物件与书内文字

重写 31 处主要观察正文，另修阶段变化文案。根据用途分别使用家信、单据、草算、工作痕迹、人物插话；不要求同样段数。人生记录用小满当时所见所闻，保留不知道、没问到的部分；不替人物补写未发生的心理结论。

现有第四章三个短对话和第五章三段结尾也清除了无指代的承诺与说理。第四、五章仍是短版流程，没有据此声称按前三章标准完成整章扩写。

## 文本如何进入实际交互

七组对话、70 个既有节点改为按顺序编排的说话与叙述回合。每回合保留自己的说话人、立绘和正文；叙述显示所在房间，小满发言时不借用旁人的立绘。文字继续渐进出现，最后一个回合读完才开放原有选项。

正式稿在 `src/content/scripts/`，场景、选择条件及奖励仍在 `src/content/chapters/`。节点的兼容正文由回合自动合成，不手工维护两份稿。阅读位置仍是临时界面状态，既有存档可以继续使用。

三张书签和对白统一为陈家六点开门、第一笼六点半，老周七点半取；送面方案明确是发好的面团，连续先试三天。手机待机画面取消所有场景通用的固定早晨时间。午餐的分钟数从排定下锅起计算，阅读不消耗真实倒计时。

## 怎样评审这一版

先读[关键场面阅读稿](叙事改稿阅读稿.md)，再进游戏看停顿、人物切换和选项。检查每个场面里有没有认知变化、人物会不会反驳、选择是否接得上刚才的话；再单看句子里有没有多余解释和一律温柔的口气。

自动检查只验证数据、分支、文本分段和兼容性。文学质量不能由字数增长或测试数量证明，也不把这一轮当作全体人物的新设定定稿。
