# 第二章生活对白版接入

2026-11-08。以用户提供并认可语言风格的[生活对白版原稿](../百味录_第二章_一笼早饭_对白重写v2_生活对白版.md)为主稿重构当前 Demo 第二章。原 Markdown 原样保留，正式对白在 `src/content/scripts/morning.ts`，场景、条件与选择在 `src/content/chapters/morning.ts`。

## 当前可玩的流程

早市见陈伯，阿宁从后院插话 → 看店里物件、去后院问报到 → 到灶间洗手，跟陈伯学皮、馅和收口 → “下一笼”认馅装笼、看火、分装 → 阿宁尝咸淡，请陈伯一起吃 → 饭桌三种收束 → 问做法、回访及给琴姐带话。

三处原场景保留。原稿的 23 个节点名和全部旧选择 ID 保留，增加柜边接话、粉笔和学生画三处可选节点；第二章现为陈伯 18 节点、阿宁 8 节点，共 26 节点。新增五处交互，章内合计 22 处，物件与人物仍是独立世界精灵。

## 新稿如何进入游戏

| 原稿内容 | 实际接法 |
| --- | --- |
| 门口重逢、做生意时插话 | 按原说话人顺序接入，老周用门外发言，不借用别人的立绘 |
| 灶间学包子 | 增加“陈伯 · 学下一笼”，指定进入 `before-food`；读完可直接接续小游戏，连续面板保持取景 |
| 五只早饭 | 老周青菜两只，阿宁豆沙一只，陈伯与小满各一只鲜肉；小满自己的那份不再漏掉 |
| 认馅与蒸制中的话 | 收进小游戏内容配置；选错陈伯的馅、提前揭盖、请陈伯带做各有对应回应 |
| 老周分两袋、陈伯放碗 | 出笼后由玩家分装，两项都对才可端走；错误回应滚动到可见处 |
| 孩子的画与三盒粉笔 | 后院两件独立道具，观察后在阿宁的谈话里开放可选问法 |
| 两张纸放一起 | 仍需备料表、班车账页和足够交谈；读取账页不自动展示给阿宁，玩家选 `morning-show-papers` 后才放上饭桌 |
| 分支后不同的补句 | 同一 `after` 节点按试行、先吃、暂缓选择不同对白，后续章节回访另换时间指代 |
| 饭盒留言 | 听阿宁托话后取得线索，琴姐初见、忙单与三种午餐收束后都能接话；带到以后不会重复作为待办 |

擀皮、揉面和试样面按原稿作为叙述、观察与人物示范，没有新增强制小游戏。蒸制仍为原有示意玩法，没有把游戏里的蒸汽数值写成现实烹饪参数。

## 三条收束各自承诺了什么

| 路线 | 当场结果 | 书页与回访 |
| --- | --- | --- |
| 试三天 | 后天六点半先送一盆，第一笼照旧、第二笼试，陈伯自己验；第三天再谈七点开门 | 柜边留下三个空格；人物和书里都写约定，不写已经试完三天 |
| 先吃 | 先把饭吃完，只答应让师傅带一盆样面看看 | 没有写成正式三天试行，也没有替他们改开门时间 |
| 暂缓 | 今天照旧，表折好放柜旁，晚上再看，阿宁仍按时报到 | 不补写承诺；陈伯与阿宁的回访各保留未说完的部分 |

正页更新为今日学到的面皮、鲜肉、青菜、豆沙与上笼观察，页边记歪褶包子和五只分法。人生记录按实际路线展示；没有给阿宁看过账页，就不在先吃路线里补写她已经看见班车记录。

## 接入时处理的衔接

- 统一为“后天先试样面”，不混用原稿回访中的“下午拿样”；七点开门保留为待议。
- 老周提前露脸后先去转一圈，按老时间回来；新的一笼分好、邀请陈伯吃饭时才记录取走两袋。
- 邀请前先去后院尝过咸淡，避免小满没听阿宁说过就谎称她说馅咸。柜边会先提醒去后头。
- 画与报到信分开，粉笔放包旁；备料表在开饭后移到后院，展示账页后才摆到一起。纸页放在桌面和前沿，避开人物的脸。
- 各路线收尾收书后清掉饭桌上的早饭，陈伯回柜边；提前放下结尾对白，再交谈可续接该路线收尾。
- 将“请几天假、锅响才岔开”同步改成这版的“能待多久、阿宁喊豆沙时打断”，只调整相关第三章与结尾回扣，没有固定小满原职业。
- 原稿的个别错字与“借给我”的指代作了澄清，其余对白主体按原稿接入，新增接话沿用原稿口气。

## 规则与兼容

内容仍 v5、存档状态仍 v3。新增 `reward` 条件只读取原有一次性动作账本，用于判断学过灶间安排、尝过早饭和送过留言；不增加必填存档字段，也不改旧决定的值。

场景对白可用 `interaction.entry` 指定节点，选项可用 `activityId` 接续物件玩法，核心同时检查所在章节、场景、物件可用性与前置条件。开发者模式仍可直接检查任何节点，必要时定位到玩法所在场景。界面只打开玩法，奖励仍由核心发放。

`DialogueNode.versions` 和 `Entry.versions` 仅替换表现文字，由原条件选择；回合里没有效果或任意脚本。六份重构前真实 v5 保存进测试夹具，验证读取后的全部状态与对话游标一致。旧门口 `before-food` 档可放下后到新灶间入口继续；已完成或后续章节进度不重置。
