## 内容与衔接

第四章三个结果均听完锁门收尾才回院；进入第五章保持 playing，任务 active。第五章有桂花小院、檐下长桌、次晨院门三处，归院打照面 → 翻三张店签 → 三札归档 → 奶奶复核 → 车次和空当 → 确认选择 → 听完当晚回应 → 次晨动作 → 结局。

三店记录以独立结果旗标读取，夜饭区分取餐、提前取消和未回信，不推断去处。不以任务成败数决定主角结局。早餐、通话、留书共用 epilogue 决定；最终选项同一前置，确认前可退出，确认后不能改选，重开车次单续接对应夜间回应。旧兜底只描写书和院门，不增添承诺。选读日历、阿川、饭团只增加交流，不补玩家未看过的线索；带袋时才出现挂袋交互。

短札小游戏复用 itinerary 纯放置和核对逻辑，独立 filing 面板；半份吃法写今天，带问号的通话夹待定，保密原话收信封。小梁与许叔札随结果变化。求助逐张读依据，仍由玩家归位确认；取消不提交，完成只记一次 epilogue-filed，不按成绩分流。

## 工程边界与兼容

终章用既有 Chapter.exit 显式表达可探索的收束门槛，无 next 但有 exit 时不自动结局。通过统一 travel 命令完成终章，界面不直接改阶段。核心无场景、人物或章节 ID 特判。最终界面先列出三家实际店记，再给最后一幕。

内容 v6、状态仍 v3、存档外壳仍 v1。迁移先按冻结的 v5 终章和结局校验，继续沿用 v2→v5 原链。前三店与回访游标保留；旧自动结局从第五章归院重读，不将自动判断当成早餐或通话的承诺。原文件读取时不改写。第四章旧短版用兼容店记，第三张为未写入私话的空信封，不凭空补出许叔或小梁的私话。

美术经过效果图 → 空底图 → 独立透明精灵 → 资产表引用，提示词与来源见 [美术记录](../art/epilogue/prompts.md)。使用现有木制控件、渐进文字、书页表现与相机回正；新增书页近景仍是平移缩放，不宣称完整分层透视。字体按官方霞鹜文楷原字体重算新增字符子集。
