## 陈伯 · 店门口、灶间与后院

### 给陈伯留着的早饭
<a id="morning-talk-invite"></a>

陈伯刚把柜台抹过一遍，见你端着碗出来，伸手想接。

陈伯：这只给谁的？

小满：给你的。肉的。

陈伯：你拿回去吧，我等会儿吃。

小满：阿宁说馅咸了，让你尝尝。

陈伯：咸了？我刚才尝的那份不是——

他看见你嘴角还沾着一点汁，狐疑地打量你。

陈伯：你尝的？

小满：嗯。

陈伯：你也尝出来了？我刚才只拿一点馅试，包进去兴许更重了。

小满：那你亲自去尝。

陈伯：……你俩是不是说好了？

他往门口看了一眼。后面没有新客人，老周已经提着两袋走出去了。

陈伯：成，我吃一口。你先端过去，我洗手。别催啊，刚摸过钱。

阿宁（后院）：那我数到三了啊！

陈伯：你数到三十我也得洗完手！

### 再见陈伯
<a id="morning-talk-opening"></a>

陈伯背对着门，刚把一笼空屉摞起来。柜台外一个人喊“青菜两只”，后头又有人问肉包还剩几个。他没抬头，嘴先应着。

陈伯：菜的下一笼。肉的有，等会儿啊，你那十块我找你四块……哎？

他把零钱攥在手里看着你。

陈伯：小满？

小满：陈伯。

陈伯：还真是。昨天你阿婆跟我说你回来了，我还当你得睡到中午。什么时候到的？

小满：昨晚。

你答得很快，还想再补一句路上没耽搁什么，又看见他攥着零钱的手没松。那声小满喊得太熟，你来时想好的几句解释忽然都用不上了，只好先站近一点，替后面取包子的人让路。

陈伯：那也没睡几个钟头。吃没吃？

小满：还没。

陈伯：正好，别走。哎，穿蓝衣服的，青菜的真还得等，你急的话先拿个馒头？……好好好，给你留着。

他终于把钱找完，拿一张纸袋塞到你手里。

陈伯：来，帮我拿一下袋子，站这边宽敞。好些年没在这儿见你了，这回能多住几天吧？

小满：还没定。

陈伯：嗯。回来住住也好。工作那边……

阿宁（院里喊）：爸！你把我的豆沙包卖了没有？

陈伯：留着呢，豆沙的在后头！小满也来了，等会儿一起吃。

他回头继续问你，声音却压低了一点。

陈伯：不急，回头再聊。你阿婆叫你来干什么？总不会一大早特意来查我的账吧。

小满：查方子。她那本《百味录》还记得吗？

陈伯：记得，纸比她那围裙还旧。你阿婆做米酒，糖放多了偏说我尝不出来。她想记哪个？

小满：包子。能问多少问多少。

陈伯：那有得讲。你先吃一只，等这几位拿好了，我带你看看。好久没来了，今天在这儿多坐会儿。

### 陈伯记得那只月亮
<a id="morning-talk-old-photo"></a>

小满：奶奶翻出张老照片。六岁那年，我在你这儿包过一个月亮。

陈伯：一个？你包了半笼。能上锅的就那一个。

小满：她说上锅以后还漏了。

陈伯：那也能叫漏？那叫开了个大口。馅从这头掉那头，屉布洗了两遍。你还不服气，说月亮上本来就有坑。

小满：都漏成那样了，你怎么还肯让我接着包啊？

陈伯：你玩得起劲呀。案板边摆个小凳子，就肯在旁边待一上午。你阿婆来接，见你袖口全是面，一边替你掸，一边还问我下回能不能再来。

小满：她说你后来还给我面。

陈伯：给呀。你坐个小凳子，谁也不耽误，就是老问“这个能吃吗”。包到最后，我说剩下的你带回去，她还以为我送了你一袋真包子，乐得不行。

小满：你是不是也没敢告诉她？

陈伯：告诉了。她说难怪你那天晚上不肯吃饭，兜里一团生面揣得热乎乎的。

### 先认认今天这盆面
<a id="morning-talk-concern"></a>

你正要进灶间，陈伯又叫住你。

陈伯：慢点，这块刚拖过，滑。往干的这边走，你小时候就总从这儿跑，我一看你过门槛，还想喊一声。

小满：我那时候多高啊，一盆面在哪儿都能撞翻。

陈伯：那时候人还没案板高呢。阿宁在后院，给我写了张新备料表，头一行就写七点开门，贴在灶间墙上了。

小满：晚开一个小时？想让你早上松快一点吧。

陈伯：松快点谁不想啊。可老周七点半还来取两只青菜，这个点怎么留，她得跟我一块儿算算。

阿宁（隔着门帘）：那张纸后面还写了送面时间！你怎么只看这一行？

陈伯：哦，我看了半天，原来是给我考阅读理解。

阿宁：你少贫！

你看见陈伯朝你扬了扬下巴，像还想接一句，门帘里已经又有人应声。他就把话咽回去，转身掀开面盆上的湿布。你本来想跟着笑两声，听见阿宁那边的急劲，又先低头看了看他手里的面。

小满：今天这个是你自己揉的？

陈伯：今天这盆我揉的。来，手洗一下，摸摸边上这团，轻轻按就行。

你洗完手，按过面团。面比想象中柔软，手指离开后，凹下去的地方慢慢鼓回来一些。

陈伯：嗯，这个能包。阿宁说有一家能送发好的面过来，我也想省点力气，可送来是什么样，我总得先看看。行了，你先去找她，我这边火上还有一锅。

### 老周的两袋青菜包
<a id="morning-talk-hours"></a>

小满：老周真天天七点半来？

陈伯：差不多。他以前开车，退休以后也闲不住。他跟我说六点起来闷得慌，来这儿走一趟正好。

小满：他老伴也来？

陈伯：她腿脚不好，在家等着呢。老周自己路上先吃一只，到家再给她一只。所以两袋，别嫌麻烦，他走路快，刚买的包子一闷就湿底。

小满：哪只给她？

陈伯：褶子收得齐的那个，青菜少放盐。你别笑，老周自己说不用挑，她又不是看包子好不好看。我说你少管，反正不是你包。

门口又来了一位老顾客，比往常早。陈伯看见他，先问今天怎么赶在下一笼前头到了。

老周：背后说我什么呢？

陈伯：说你走得快！你的还在下一笼里，先转转，别一会儿连小满那只也拿走了。

老周：他回来了啊？哟，真长这么大了。小时候那个月亮还包不包？

小满：你们怎么都记这个？

老周：当然记。你守着那只月亮包子，见人就问像不像。我回去还跟你阿婆讲，小满今天也会包了，可把你高兴的。

老周看了一眼灶间，说那我先转一圈，老时间回来，别把两只合成一袋。陈伯应着，拿纸袋的手还没停。

可接的话：

- 看来今天这方子还得认真学。

### 护膝和小凳子
<a id="morning-talk-knee"></a>

小满：盒盖写着走楼梯的时候戴，旁边还有你回的一个好。

陈伯：我写的。她回来要看看，我就写上，省得她挂着这事。

小满：我给你放回那一格，跟纸袋分开。

陈伯：对，那边干爽，放着好找。

小满：那张小凳子怎么还在柜底下？

陈伯：以前怕挡路，收进去了。你看钱匣子这边，空出来倒是能放，伸手还能摸到袋子。

他朝柜台外侧比了个位置，又给拿好早饭的客人让路。

陈伯：有空帮我挪一下吧。我就坐这边，门口来人也看得见。

### 陈伯陪你练下一笼
<a id="morning-talk-before-food"></a>

陈伯从大面团上切下几块，摆到你手边。案板有一道旧划痕，细粉落进缝里，抹也抹不太平。

陈伯：来，本子搁旁边干柜上，我给你留一块面。手洗过了吧？

小满：洗了。

陈伯：一会儿要直接碰面，咱们再冲一下，我也顺手洗了。这块给你留着。

你们冲过手回来，陈伯先将一小块面搓成长条，让你站到旁边看。

小满：你不等我啊？

陈伯：那我再搓一小条给你看。来，这块你拿着，先搓圆，压扁一点，边上慢慢擀。

你擀了两圈，面皮成了一个怪形状。

陈伯：先停一下，中间有点薄了。我给你托着，你看，放馅的地方要留厚一点。

小满：这不还有一层吗？

陈伯：放了馅还得兜得住。咱换一小块再来，慢点转，手跟着走。对，这回就好多了。

他把三盆馅挪近了些。青菜的颜色亮，豆沙搓成了小球，肉馅拌得细密，筷子挑起时能牵出黏黏的一缕。

小满：肉馅怎么这么稠？我在家拌出来老是出水。

陈伯：你是不是一碗水倒进去，拿筷子转两下就算拌了？

小满：……差不多。

陈伯：水得分着添。先把肉拌出点劲，少倒一点，等搅进去了再添。你看，盆里不浮水，筷子挑起来也不散。你先试，等我手擦干了，再陪你把这几行写清。

小满：盐呢？奶奶特意让我问清楚，别又写“少许”。

陈伯：我先称一盆给你看，回去还得按你买的肉改，肥瘦不一样。咸淡就取一点蒸熟了尝，生的别碰嘴。今早这一盆我都觉得略咸了，你等会儿吃吃看。

小满：菜的又怎么弄？

陈伯：菜洗好把水沥干，出水多的先处理过，别带着一盆水往面里塞。老周那份少盐。豆沙不烦你，现成搓好了，往里放，别贪大。你要没地方收口，别说这面不听话。

小满：我这只像不像？

陈伯瞧了一眼。

陈伯：像了。头一只都这样，我刚学时也收不好口。

小满：那也叫包子。

陈伯：这就叫包子。收口再捏紧一点，先放一会儿，等它松起来。今天蒸屉你来照看，我在旁边，什么时候能揭咱们一块儿看。

前头叫了一声“还有包子没”。陈伯伸头应话，回来发现你正一笔一笔记。

陈伯：先别写那个“拌到有劲”，你自己摸过没？

你照他说的用筷子挑起肉馅，又试着把刚擀的皮托到掌心。

小满：……是跟我家那盆不一样。

陈伯：摸过就有数了。来，装下一笼，你包的那只单独留着，出锅咱们一起尝。

### 坐下来尝一口
<a id="morning-talk-table"></a>

陈伯最后一个坐下。他先试了试凳子稳不稳，坐下以后也没立刻吃，朝门口喊：

陈伯：前头那笼先别开！我都交代过了啊！

阿宁：没人要开！你都关火了还惦记。

陈伯：知道了知道了。

阿宁把肉包往他面前推。

阿宁：尝啊。小满说咸。

陈伯：小满还说他今天包得像样呢。

小满：我可没这么说。

陈伯：我听你那意思就是。

陈伯咬一口，嘴里嚼着，没有评价。阿宁盯着他。

阿宁：怎么样？

陈伯：嗯。

阿宁：“嗯”是什么意思？

陈伯：意思是你让人先咽下去。……今天这盐是略重了点。你早上往里头加了酱油没有？

阿宁：我没碰你的肉馅！

陈伯：那就是我这边多抓了一点。明天这盆得改。

小满：我觉得还挺香的。

陈伯：香是香。咸也是真咸。你书上别写错，肉馅那一行，盐记少一点。明天照这盆肉来算。

你掰开自己包的那只。馅偏到一边，左边厚厚一层面，右边的皮薄得快透了，倒没有破。

陈伯：看。这个给你自己吃正好，卖不成。

小满：为什么？又没漏。

陈伯：客人不挑？一口咬下去全是面，第二口全是馅。你要给自己做，倒是有惊喜。

阿宁：哎，我觉得挺好。有的人就喜欢第一口吃面。我以前上学不肯吃肉，专挑皮子啃。

陈伯：是，馅留给我，皮全归你。我还真养过这样的孩子。

阿宁没接着斗嘴，拿起那只已经放凉的豆沙包，撕下一点边沿。她吃了一口，抬头看父亲。

阿宁：你怎么来这么早？我昨天刚听奶奶说你回来了，还想着晚点去她那儿。行李放好了？

阿宁：那就好。我昨晚还想过去，看你到得晚，怕你没睡够，想着今天再找你。

她给你拉了把椅子，椅面是干的，靠背上却搭着围裙。

阿宁：凳面是干的，你坐这里。围裙我拿开，免得沾到背上。吃东西没有？

小满：陈伯刚给我塞了个袋子，包子还没到嘴。

阿宁：他是不是一见你就问能待多久？

小满：问了。

阿宁：他就爱问这个，怕你一转眼又走了。今天多待会儿，咱们一块吃早饭。是奶奶托你来的？

你把《百味录》给她看。

阿宁：哎，这本还在啊。你小时候不是老说上面那个碗有腿，跑得比你快吗？

小满：奶奶还记着。

阿宁：我们家也有本旧的，记顾客口味。上次拿去晒，风一吹全是油香。你等等啊，我把这个挂上。

她把笼布抖开，夹子咬住一角，又被风掀起半边。折腾完才接着说。

阿宁：你来得正好，今天有新鲜事。我要去城南小学了。

小满：去你实习过的那边？恭喜啊，陈老师。

阿宁：听见你这么喊，还真有点不习惯。前天通知下来的，我正想找个人讲讲。

小满：那我来得正好，你给我说说。

阿宁：好，你进来看，我还带了孩子给我画的教室。

### 去城南小学的报到信
<a id="ning-talk-school"></a>

阿宁从帆布包侧袋里抽出报到信，又朝干柜上层那张画指了指。画上窗户画得很大，桌子只有三条腿，讲台上的人穿一件蓝裙子。

阿宁：你看，这是我实习带过的班。画画那孩子叫小朱，上次考听写，硬是把“月亮”写成“月饼”。我问他怎么回事，他说饿了。

小满：这理由挺好。

阿宁：我当时也想笑，没敢笑。后来批本子，越看越想笑，还把教案忘教室了。学校这回招人，正好缺一个老师，我报了，前天通知下来了。

你想起刚才那声陈老师，原本半句玩笑，这会儿看见通知上的字，才知道她是真的要去一个新的地方了。你也替她高兴，可一句恭喜说过以后，又不知道该接什么，先问起了店里这边。

小满：你爸知道吗？

阿宁：知道啊。他怎么会不知道，我那天回来就跟他说了。他正在搬面，嗯了一声，然后叫我把门带上。

她把报到信给你看，落款还压着一条新折痕。

阿宁：你说他听没听着？我也不知道。昨天我问他下星期一谁先开门，他说照旧。可我星期一一早就得出发，哪能照旧。

小满：店里以前都是你帮着开的？

阿宁：我上学也忙，不过只要回来就得搭把手，早上拿单子、数包子、换零钱……习惯了。就我们俩在店里，谁干哪样连说都不用说。我走了他才要头疼。

她说着说着忽然笑了。

阿宁：我跟你讲，我这两天把报到的东西买了一堆。粉笔、文件夹、黑笔，明明学校都有，还是忍不住买。买回来摊一床，发现自己连去那边住不住都没想好。

小满：挺像我。我昨晚也把包摊一地。

阿宁：你那包里好歹是衣服。我买了三盒粉笔，摆出来自己都笑，真去报到反而用不了这么多。

### 她改过的备料表
<a id="ning-talk-plan"></a>

阿宁：喏，就是它。你别看我写得挤，晚上改了好几回，纸都快擦破了。

她把表铺在椅子上，又怕风吹走，拿杯子压住一角。

阿宁：我找了个做面点的师傅，能提前发好面送过来。先少送一点，让我爸试试。省得每天四点多就起来和面。你看，他昨天站久了，晚饭后又在院子里走半天，问他怎么了，他说消食。他吃了才半碗，消哪门子食。

小满：陈伯看过这表吗？

阿宁：看了前两行。看见“开门晚一点”就说不行，老周要来。我说老周那两只可以提前留，他就说我压根不懂老周。我哪不懂啊？七点半他要两只青菜，分两袋，给阿姨那只褶子要好看些，我闭着眼都能拿。

小满：那送面的师傅怎么说？

阿宁：说可以先试，出了问题当面讲。他卖面给别家做包子也不是头一回。不过我跟爸说了，这样弄只是试一试；送来的面不好，咱们就不要。他偏盯着我问：要是他迟到了，你拿什么给客人？我说那天先不改开门时间，照旧做，拿第二笼来试。他又说我多此一举。

小满：听着挺费劲。

阿宁：可不是。今天早上我跟他讲了半天，讲到最后我自己也上火。他说一句“我的面我知道”，我一听又想跟他吵。

小满：你拿这表去说，他可能还真觉得你要把锅给端走。

阿宁：锅那么沉，我才不端。说真的，我已经够忙了。学校还让我准备一节试讲课，昨天半夜才弄完。我就想他白天能坐下吃一顿饭，能少揉一盆面也好。

你注意到表角有一行写了又划掉的小字：“别一开口就吵”。

小满：这个也是计划里的一条？

阿宁：……哦，这个你别看。写着提醒我的，没什么用。早上刚讲两句就忘了。

### 高兴，也挂心家里
<a id="ning-talk-not-said"></a>

小满：你去上课了，早上再回来帮这一趟，确实赶不过来。

阿宁：所以想先把送面的事试起来。他腿疼我也挂心，问他歇不歇，他总说出完这一笼再说。等真忙完，又是晚饭时候了。

她看一眼前门，声音小了一些。

阿宁：不过我也盼着走。说起来挺不好意思的，我现在一看见那张报到信就高兴，买粉笔都高兴。刚才跟他吵完，又觉得高兴得太早了。你说烦不烦。

小满：你盼着去学校，也想他少累一点，两件都得挂着，难怪这几天总睡得晚。

阿宁：是啊。好些话在他面前越讲越急，跟你倒能慢慢说。

小满：我先听着。你要找人试讲，也可以找我，我这几天有空。

阿宁：那我先记下这句话。你帮我把水池那头的碗拿一下，我把这张画收好，省得一会儿又沾水。

阿宁：你这趟回来，还走吗？

小满：可能吧。

阿宁：嗯，那也挺好，先回来歇歇呗。我爸一见人就爱问住几天，你也别急着给他报个日子，等想好了再说。

### 先尝那只鲜肉包
<a id="ning-talk-ready"></a>

阿宁把老周的两袋摆好，又从笼里挑了一只肉包，放进一只缺了口的白碗里。

阿宁：这是爸的，你替我看着，别让他又递给客人。上回我给他留了三个，回头自己只吃了半个，我问他另外两个呢，他说老周带走了。老周还以为他特意请客。

小满：我去喊他。

阿宁：你别喊“歇会儿”。这么多年了，他一听见这两个字就忙给你看。你说馅咸了，让他过来尝。

小满：不是说要讲实话吗？

阿宁：你就咬一口再说，万一真咸呢。

你掰开自己那只鲜肉包，先咬了厚皮的一角。刚才在案上还嫌它丑，真捧到手里，却舍不得一下吃完。热气顶上来，肉馅的姜葱味里果然带着一点重盐，你抬头看阿宁，她已经等着你答了。

小满：……好像真的有点咸。

阿宁：你看。行，去吧。咱们家这位陈师傅，只有这个最管用。

- 我把这只端过去。

阿宁：表我折好放柜旁了。他说晚上看，我先去收教案。下周一还是得照常报到，这边的话，等晚上再接着说。

她把书还给你。

阿宁：你待会儿去琴记？替我带句话，上回借的饭盒洗干净了，过两天送去。就这一句啊，别替我约一顿饭，回头她还得专门留。

可接的话：

- 行。那你也记得吃午饭。
- 饭盒那句话，我替你记着。

### 买回来的三盒粉笔
<a id="ning-talk-chalk"></a>

小满：那三盒粉笔，真都准备带去？

阿宁：学校有，带一盒就够。买的时候总想着这个也得用，那个也得备，拿回家一倒，床上都没地方放教案。

小满：留店里一盒，给你爸写菜单。

阿宁：他能写？字一大，写到最后连个包字都挤不下。上回把价钱写旁边，客人还以为一次要买那么多。

她把开着的盒盖按上，又将纸袋往门里挪了挪。

阿宁：先给我留一盒整的，报到带过去。剩下的搁家里，我回来慢慢拿，菜单上用得着也能先用。

可接的话：

- 我把袋子往里收，别再绊着。

### 给陈老师画的教室
<a id="ning-talk-drawing"></a>

小满：小朱那桌子还给画了抽屉，三条腿能撑住？

阿宁：画里撑得住。你别替他添第四条，他专门交代过，说被挡住的不用画。

小满：你给他留原样？

阿宁：当然留。我讲课的时候站那儿，他画成穿裙子的小人，我也没让他把头画大一点。

她顺着背后的胶带抚平纸角，没有再折一道。

阿宁：等哪天真坐到他旁边改作业，他还不知道要往哪里藏本子呢。你帮我夹好，别沾水。

可接的话：

- 我原样夹好，不给他多画一条腿。
