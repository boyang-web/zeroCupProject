# 创作与语言约定

更新：2026-11-07。根据用户对语言生硬、模板化及事实描述过重的反馈调整。此约定用于游戏对白、旁白、手记和界面文字；工程说明仍以准确为先。

本轮剧情重策划说明：以下叙述与表达要求继续适用；具名人物的口气例子来自现有 Demo，不锁定新剧本的人物性格、关系和经历。新设定见 [剧情重策划工作稿](planning/剧情重策划工作稿.md)。

## 叙述

用户最新明确要求更充分的叙事、沉浸感和人物语气。减少套话不等于把内容压成事实摘要；应留出对话来回、停顿和小满当下反应的篇幅。此前扩写增加了长度，仍存在说明过满、物件套同一结构、人物都在分析自己的问题。最新实践见[叙事调研与前三章改稿](planning/叙事调研与前三章改稿.md)，字数不作为文学质量的验收指标。尚未讨论定稿的人生设定不据此固定。

先写眼前能看见、能听见的事。人物把纸折起来、没动筷子、把那张凳子挪近，都可以留给玩家判断。避免每段最后再加一句“原来温情就是……”来解释已经发生的事。

不用抽象词替代物件。“缺口朝里，水已经不烫”比“杯中蕴含着无声的关怀”更适合这里。可以有比喻和停顿，但要属于这一刻，不为每一件东西配一条格言。

主角可以想起一件旧事，不替所有玩家断言自己已经懂得了人生。获得的线索只记录已经看见或听到的内容，猜测与事实分开。

每场交谈先确认人物要办的事、没说出口的顾虑、双方各自知道什么。不要让人物在见面第一回合交出全部背景和动机，再要求玩家找一次物件复述。发现物件之后，至少有一句话应因此改变。

观察文字按物件的用途选写法：信可以直接读，单据保留未算完的工序，熟悉的物件也可以只有一句新发现。不规定“材质、童年、感悟”三段式；动作要影响谈话或实际做事，不能每次换成捏杯沿、压书角就算有叙事。

## 人物

- 祖母先问有没有吃、外套放哪儿。她愿意打趣，也会略过工作的问题，不负责逐句说出主题。
- 陈伯讲话短，常借灶上的事岔开话头。他会说“挡路”，也会在玩家转身后坐上刚挪来的凳子。
- 阿宁会急，会把剩下的话咽回去。她有自己的工作打算，父女的温情不以她接店或留家为结论。
- 琴姐忙时说事直接，慢下来才顾得上问一碗面要放多少醋。她也会忘记把自己记得的习惯写给帮手看。
- 阿川在计算订单，也在担心自己帮了倒忙。他的接单办法有现实理由，可以修正，不把他写成不懂人情的反派。
- 田姨的时间很具体。她赶回对街做活，也给面馆缝门帘；来店里的人有自己的事情，不只等着玩家同情。

小满是带着自己处境回来的人。他可以回避、误解、嘴笨，也会想帮忙；不默认他擅长劝和或经营。配角可以纠正他，人物彼此也要直接说话，不全朝向玩家自述。温暖不要求每场都有和解、保证或一句能摘出来当格言的话。

## 界面

按钮说清楚会做什么：进灶间、移出、读档、回去。必要操作说明可以直白，不需要全部改成诗。

减少“心意已记下”“回响仍在继续”一类每次出现都相同的抒情提示。奖励若有对应人物回应，直接给出那句回应；保存状态就写“进度已保存”。

文艺感来自场景、动作、语气与留白的配合，不能只靠整齐的短句、温暖的形容词和反复出现的书页比喻。

## 本轮的适用范围

第一至三章的现有对白、主要观察与手记按调研结论重写；第四章短稿与结尾短文作有限清理。使用本地 humanizer-zh 技能辅助检查；它是表达检查工具，不代替对剧情和文学质量的判断。剧情先读成完整场面，再检查句子，不能只靠搜禁用词或把长段切成短句验收。
