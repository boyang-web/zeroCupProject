# 续读首页书本精修

2026-11-11。基于 submission/2026-zero-cup 的 4665bad，修改的是本地最新版本目录，不覆盖旧开发目录。

## 改动

续读入口拆为 HomeBook.vue。书脊、纸张切口、正文页与封皮正反面分层；使用 entry-volume 前缀隔离全局书内样式。封皮绕左侧铰链旋转，封里独立反向面渲染，半开及打开后不再只剩单层封皮，也不会出现书内中央轴穿过封面。首页废弃的拖动推进逻辑同时移除。

视觉复用已登记纸纤维纹理，新增布面细纹、封皮衬板、缝线、题签、细框、藏印、纸页层、内页与丝带。不覆盖原图或字体。短拖动平滑回弹，超过阈值顺势打开；键盘回车和空格可等效继续。完成打开时保持开合姿态再进入原存档，幕间文案改为“续上这一页”，避免错误显示“第一章”。

## 入口与声音补充

默认打开网站始终显示百味录首页。翻开书：无存档进入完整引子，已有存档直接续读。显式 `?intro=1` 仍仅供预览引子。

翻书与末幕门环增加可见的向左拖动短句和方向动画，并注明回车等效操作；拖动中淡出，减少动画设置下方向动画静止。提示独立于会旋转的封皮，避免翻开中穿层。

TitleScreen 将引子展示状态通知 App，音频在已有用户翻书操作解锁后于引子使用 home 主题播放。静音和音量设置保留，隐藏页面仍暂停；进入正式剧情由原有主题选择衔接，未增加独立音频播放器。

## 动画连续性修订

按最新反馈移除回车翻书与开门的可见提示文字，键盘功能仍保留。书封开始拖动时读取当时实际显示的悬停角度，不复位至关闭角；拖动阶段取消 CSS transform 过渡，避免与逐帧角度更新叠加。松手后采用按剩余距离计算时长的 ease-out，完成回调直接交还入口，不再先启动一个独立650ms计时器。续读去掉额外1100ms幕间等待。门板拖动改为直接跟随指针，松手后的开门动作与淡出并行，取消原先600ms淡出延迟及1550ms的完整等待，保留小幅拖动回弹和减少动画设置。
