## 新开场与修正

合入序章、城市、消息、归途、家门五幕滚动引子。书本主题可翻，手机可查看日历、临时编辑简介和回复奶奶，最后拖门环或轻触开门；键盘保留等效操作。有存档直接进入原首页，继续原进度。引子中的文字编辑与发送只属于本次演示，不写入剧情档，不发往外部服务。

家门图片来自用户压缩包，包内登记为 imagegen 生成，来源登记与图片一并保留。本轮没有再次生成或覆盖原素材。

实测发现 Chrome 将 sticky 容器内获焦的手机按钮滚回其原始布局位置，日历返回后甚至退回第一幕。现保留原生滚动，在获焦时恢复当前阅读位置，手机的日历、返回、草稿和消息均可连续操作，不再触发分幕倒退。教学保留目标标题、聚焦和指引线，去掉步骤数与重复点击说明；需要实际说明的书签任务仍有正文。

## 人间百味

用户反馈前稿仍像对白与事实摘要，希望语段有文学性、密度、细节和情感。已以压缩包的新稿为底重新写完 11 篇正文和 7 个条件版本，保留其标题、ID、条件和插图。正文集中于小满所见、所想与人物行动之间的联系，不在每段末尾再归纳一个道理；各篇有自己的重心，不统一套“动作、感悟、收书”结构。

奶奶的两段旧事仍按实际听过的内容分版；只听过认错门时不补煮米酒。陈家账本只在展示过后进入对应片段，试样、先吃和暂缓各有不同的余地。琴记不替人物轻易抹掉少接一单的损失，也不把小满临时帮忙写成长期人手。夜饭不泄露未问过的家事，不推断对方已读、到过哪里或已经原谅；修正包内尚未吃饭就写吃过、关灯动作前就写离店的提前叙述。

可直接阅读[人间百味新稿](../百味录_人间百味_片段精修阅读稿.md)。[全站稿](../百味录全站剧情文本.md)和第四、五章派生稿通过 `npm run export:story` 更新；两个用户原稿不参与导出覆盖。
