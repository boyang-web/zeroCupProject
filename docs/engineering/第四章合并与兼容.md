- 第四章正文移入 `src/content/scripts/night.ts`。人物发言与动作编排为既有 `DialogueBeat`，节点兼容正文由 `scriptNode` 自动合成；阅读回合不发剧情效果，选项仍在最后一回合后开放。

- 饭团回忆保留晚归与给奶奶回消息的内容，未将“曾做夜班”固定为小满的职业经历。对应旧 ID 保留。
