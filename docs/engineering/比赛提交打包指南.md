## 附录 A：只读素材扫描脚本

在仓库根目录运行；只读，不删除任何文件。输出可直接用于 staging 裁剪。

```js
// scripts/submission-assets.mjs
import { content } from '../src/content/index.ts';
import { readdirSync, statSync } from 'node:fs';
import { join, relative } from 'node:path';

const root = 'public';
const all = [];
function walk(dir) {
  for (const name of readdirSync(dir)) {
    const p = join(dir, name);
    const s = statSync(p);
    if (s.isDirectory()) walk(p);
    else all.push({ path: relative(root, p).replaceAll('\\', '/'), size: s.size });
  }
}
walk(join(root, 'assets'));

const urls = new Set(Object.values(content.assets).map(a => a.url.replace(/^\.?\//, '')));
for (const f of [
  'assets/fonts/BaiweiHand.woff',
  'assets/fonts/BaiweiTitle.woff',
  'assets/fonts/LXGWWenKai-OFL.txt',
  'assets/fonts/NotoSerifSC-OFL.txt',
  'assets/fonts/README.md',
  'assets/audio/manifest.json',
  'assets/audio/README.md',
]) urls.add(f);

const used = all.filter(x => urls.has(x.path));
const unused = all.filter(x => !urls.has(x.path));
const missing = [...urls].filter(u => !all.some(x => x.path === u));
const mb = n => (n / 1048576).toFixed(1) + ' MB';

console.log('all:', all.length, 'used:', used.length, mb(used.reduce((n, x) => n + x.size, 0)));
console.log('unused:', unused.length, mb(unused.reduce((n, x) => n + x.size, 0)));
for (const x of unused) console.log('UNUSED', x.path, (x.size / 1024).toFixed(0) + ' KB');
for (const m of missing) console.log('MISSING', m);
```

运行：

```sh
node --experimental-strip-types scripts/submission-assets.mjs
```

## 附录 B：PNG→WebP 示例

只在 staging 根目录运行；先按附录 A 生成“已引用 PNG”清单，再逐项转换。保持原尺寸，避免区域坐标失效。

```python
from pathlib import Path
from PIL import Image

src = Path('public')
# used.txt：每行一个 assets/...png（从附录 A 的 used 清单筛出 PNG）
for line in Path('used.txt').read_text(encoding='utf-8').splitlines():
    p = src / line.strip()
    if p.suffix.lower() != '.png' or not p.exists():
        continue
    out = p.with_suffix('.webp')
    Image.open(p).save(out, 'WEBP', quality=82, method=6)
    print(p, p.stat().st_size // 1024, 'KB ->', out.stat().st_size // 1024, 'KB')
```

转换后把 staging 的 `src/content/assets.ts` 和各 `*-regions.ts` 中资产路径的 `.png` 改为 `.webp`，重新构建并实际检查。
