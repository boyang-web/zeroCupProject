# 首页续读书本修正

2026-11-11。首页书页块用了 book-binding，与纸本中央书轴同名，因而继承了 28 px 宽度、z-index 3 及窄屏隐藏规则，造成封面上出现纸轴和开合穿模。

首页改为 home-book-pages、home-book-cover、home-book-ribbon，书页在第0层、封面第2层，书签在两者之间；页块按书的宽度伸展，窄屏仍显示。纸页厚度由纸页块表现，不再随封面阴影一起转动。拖动超过阈值后保持开合姿态，待过渡完成再进入原存档，松手不足阈值则回弹。

本机独立 Chrome 在1440×900、390×844、844×390及DPR1.25验证，取消拖动和成功续读均正常，续读前后的剧情状态一致。截图与报告见 [home-book-v14](../art/previews/home-book-v14/browser-report.json)。
