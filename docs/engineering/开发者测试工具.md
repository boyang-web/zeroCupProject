# 开发者测试工具

2026-11-06。用于直接检查现有 Demo 的场景、对白、小游戏和界面，跳过剧情先后与功能开放条件。第四、五章目前仍按代码中的短版呈现；新增故事设计稿尚未接入。

## 打开与退出

- 在首页或游戏菜单中打开「设置」，点击「开启开发者测试模式」。
- 按 `F8` 可进入测试模式并打开工具；正在交谈或操作物件时也可用。
- 本地开发可直接访问 `http://127.0.0.1:5173/?dev=1`。预览版和部署版同样支持在网址后添加 `?dev=1`。
- 开启后顶部显示测试标识。每个面板右上方也有「测试工具」，可随时重新选择目标。
- 点击「退出测试」恢复进入前的正常进度、对话与位置。模式开关不写进存档；不带 `?dev=1` 的页面重新打开时按正常规则运行。

## 可以测试的内容

| 分类 | 操作 |
| --- | --- |
| 章节与场景 | 直接进入五章中的任意已有场景；第五章进入当前结局 |
| 人物与物件 | 按名称或 ID 查找全部交互，包含剧情条件尚未满足的目标；自动定位后打开 |
| 全部对白 | 搜索对白内容、说话人或节点 ID，直接进入指定节点；条件选项与互斥选项均可选 |
| 小游戏 | 无前置打开任意已注册小游戏；也可用「测试：直接完成」检查规则奖励和后续对白 |
| 功能面板 | 直接打开食谱、人物页、全部收藏、道具、拾零、回访、测试存读档和设置 |

场景通路与隐藏物件全部开放；递茶、观察选项和收藏研究可以重复。切换同一组重要决定时，更新该组的分支旗标。物件状态、画面变体、对白的重聊入口仍依据测试中实际发生的事变化；需要查看特定后续对白时，直接使用节点列表。

道具和数值奖励按原有 `onceKey` 去重。小游戏的错误结果仍被拒绝，取消不发奖。未存在的存档会提示无记录；翻页仍等待当页动画完成，测试模式下可从首尾循环翻页。

「清空测试进度并重测此处」会从空白测试记录重新定位当前场景。手动测试档位保留，适合分别测试不同完整路径。

## 进度与实现边界

正常存档沿用 `baiwei:<内容 ID>:v1:<档位>`；测试存档使用 `baiwei:<内容 ID>:developer:v1:<档位>`。自动档、关键选择前检查点、三个手动档位和内存检查点分别隔离。测试导出的文件名带 `test-`。正常存档格式与内容版本不因测试开关改变。

`RuleOptions.developer` 是运行时传给纯规则的执行参数，不属于 `GameState`。跳场景和跳对白通过 `dev-jump` / `dev-dialogue` 命令进入核心；未开启测试模式时拒绝这些命令。Vue 负责入口和工具显示，不自行添加剧情奖励。显示全部书页、物品与收藏也不会把它们自动记作已获得。

退出测试只恢复剧情进度。音量、物件提示和减少动画仍使用原有游玩设置。

自动验证覆盖所有已有场景与对白节点、越序选项、重复决定、小游戏去重、存档位置合法性、独立档位和退出恢复。浏览器视觉、焦点、触屏与快捷键的实测结果见[验证记录](验证记录.md)。
