# 设置中的章节重玩

2026-11-10。设置新增「重玩该章节」，仅在进入故事后显示。按钮使用现有木制按钮，二次确认沿用木框、纸面与桂花装饰，并收紧为居中小窗。显示实际章节名称和清理范围，默认聚焦「继续当前进度」；取消、Esc 与关闭按钮均返回设置，不修改进度。

确认后通过 core 的 replay-chapter 命令恢复当前所处章节的首场景与初始任务。按内容归属清除本章及后续章节的对白奖励、普通标记、线索、道具、属性贡献、任务、决定、走访与相关成就；保留先前章节事实。回访时以正在看的章节为准，确认框额外说明后续行程也会清空。共享 onceKey 只扣除一次，不使用 ID 前缀判断归属；图鉴补记按来源与开放条件清理。内容 v6／状态 v3 不变，没有新增必填存档字段。
