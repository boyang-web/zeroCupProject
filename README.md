# 百味录

一款以归乡、街巷和小馆为背景的网页叙事游戏。玩家受祖母委托补写《百味录》，通过交谈、观察物件和动手帮忙，了解三家店里的人和事。

项目仍在开发。第一至四章已有专用剧情和美术，第五章仍为自动结算版本。

2026-11-06 开始完整剧情重策划，现有故事按 Demo 看待。创作采用现实人物群像，先建立环境与人物；明线收集小吃食谱，暗线了解故事并采取行动。当前以武汉东湖新村等真实街区的生活背景为参考讨论环境，见 [剧情重策划工作稿](docs/planning/剧情重策划工作稿.md)。

已接入的系统包括：

- 全视口情景、独立人物和物件精灵、悬停与键盘聚焦反馈、章内场景切换。
- 条件对话、线索与跨章补记、章节属性、道具、任务完成与局部失败。
- 可替换的小游戏模块、一次性奖励、成就及基础多结局判定。
- 自动存档、关键选择前检查点、三个手动档位，以及存档导入、导出。
- 木制与纸面风格的界面、环境声、减少动画设置及全屏按钮。

本轮入口与第一章采用新制作的木框、纸面、桂花独立装饰和本地字体；首页逐项渐入。《百味录》第一章只展示食谱，进入第二章即可回访奶奶家，第二章局部故事收束后开放人生记录，第三章进入后开放物件收藏。回访会保留此前行动，并能返回原来的章内位置。展开与实现说明见 [入口与第一章精修](docs/planning/入口与第一章精修.md)。

第一章主环境改为[老宅生活布局](docs/planning/第一章老宅生活布局.md)，物件按日常用途放置。第二章按[营业与生活布局](docs/planning/第二章营业与生活布局.md)重构店门口、灶间和后院。已接入取景的场景中，点物件先靠近，退出物件或结束对话后自动回到标准全景；连续翻书等操作结束后再回正。当前使用分层图片和平移缩放，完整透视视差仍需后续制作。

对白、物件说明和翻开后的纸页采用渐进显字。对白窗口内点文字、人物区域或留白，可补全当前句，再点进入下一句；最后留在回答处，需点选具体回答。原有快读、继续和键盘按钮仍保留。第一章教学用柔和压暗与细箭头聚焦物件，展开时只允许操作当前目标，收起后可自由探索；界面随读书、理书签的步骤渐进开放，镜头回正后再呈现下一步。窄屏指向可见入口，详见[渐进阅读与窗口教学](docs/planning/渐进阅读与窗口教学.md)。

《百味录》使用细纤维纸面、布面封皮、独立纸叶与书脊，食谱有页边小字。第二章场景右下角可直接回奶奶家，回来接着原房间进行，见[纸本与叙事扩写](docs/planning/百味录纸本与叙事扩写.md)。

## 从源码启动

需要 **Node.js 24.15 或更高版本**，并使用随 Node 安装的 npm。项目没有后端、账号服务或必填环境变量，也不需要 API 密钥。

```sh
git clone https://github.com/boyang-web/zeroCupProject.git
cd zeroCupProject
npm ci
npm run dev
```

打开终端打印的地址，通常为 `http://127.0.0.1:5173`。端口占用时以实际输出为准。停止服务按 `Ctrl+C`。

Windows 下也可运行 `npm run preview:local`，自动启动或复用本工程的预览服务，并用本机 Chrome／Edge 打开。预览浏览器使用 `.tmp/local-browser-profile`，测试进度与日常浏览器分开。可加 `-- --port 5174` 换端口，或加 `-- --no-open` 只启动服务。这条入口可用于内置浏览器连接失败时的实际交互和截图验证。

首次克隆不包含 `node_modules/` 和 `dist/`。安装依赖后即可使用开发服务器，无需先构建。

## 构建和成品预览

```sh
npm run build
npm run preview
```

构建结果输出到 `dist/`，预览地址通常为 `http://127.0.0.1:4173`。不要直接双击 `dist/index.html`，本地文件协议会限制模块与资源加载。

Windows 也可以在完成构建后双击根目录 `START.bat`。这个入口需要 Python，会启动 `scripts/preview.py` 并打开浏览器，使用 8780–8789 中的一个空闲端口。它用于查看已有成品，不代替依赖安装和首次构建。

若不希望自动打开浏览器：

```sh
python scripts/preview.py --no-open
```

Python 不是正常开发与 Vite 预览的必需项。只有重算精灵图集区域时，`scripts/register-sprites.py` 才另外需要 Pillow；普通运行无需执行它。

## 操作与存档

鼠标移到物件上会显示可选反馈，点击后观察、交谈或操作；键盘可用 `Tab` 选择目标、`Enter` 确认，`Esc` 关闭面板。左下“手头的事”可展开，右侧牌子用于切换房间。全屏需点击右上角按钮启用。

存档保存在当前浏览器的本地存储中，没有云端同步。清除网站数据会移除本地进度；换浏览器、域名或端口也会看到不同的存档，可以先导出文件备份。

当前内容版本为 v5，状态格式为 v3。第四章旧短版未决定的存档从新店门重读，前三章保留；已经结算的短版保留原结果，不补写新剧本的取餐与私札。旧 v3 第一章仍从精修入口重读，后续章节补齐回访记录；v2 仍经过原迁移链。读取迁移不会改写原文件。详见[第四章制作与验收](docs/planning/第四章制作与验收.md)。小游戏中途退出后从本轮开始处重试。

## 检查命令

开发者可以从「设置 → 开启开发者测试模式」或按 `F8` 打开测试工具，也可访问 `http://127.0.0.1:5173/?dev=1`。测试模式放开剧情前置、场景通路、全部对白与功能入口，并提供任意场景、物件和小游戏跳转。测试档位独立保存，退出时恢复原来的正常进度，详见[开发者测试工具](docs/engineering/开发者测试工具.md)。

```sh
npm run typecheck
npm run check:content
npm test
npm run build
```

| 命令 | 检查内容 |
| --- | --- |
| `typecheck` | Vue 与 TypeScript 类型 |
| `check:content` | 五章连接、场景与对话引用、条件、小游戏注册及资源路径 |
| `test` | 分支可达、场景限制、奖励去重、存档恢复与迁移、小游戏判定 |
| `build` | 类型检查及生产构建 |

测试通过不能代替浏览器试玩。当前素材仍需压缩与加载预算评估，目标浏览器、慢网和移动设备表现也需要继续检查。

## 项目结构

```text
src/
  core/             状态契约、纯规则、场景访问与内容校验
  content/          章节、对白、线索、道具、奖励和资产登记
  runtime/          Vue 状态与规则、存档的装配
  features/         探索、对话、小游戏、手记、存档和设置
  presentation/     木制界面、物件画面与动画表现
  infrastructure/   浏览器存储与音频适配
  shared/           复用控件、图标和资产显示
  styles/           视觉变量、布局和控件样式
public/assets/      运行时所需的图片、图集、声音及模型样本
tests/              规则、流程和存档测试
scripts/            内容检查、精灵登记和成品预览
docs/               策划草案、协作约定、工程记录和素材提示词
```

旧工程、素材原件及历史压缩包在本地归档保留，不属于正式运行依赖，也不随此仓库上传。依赖、构建产物和缓存同样不入库；重新克隆后按上面的命令安装和构建即可。

## 技术与素材

使用 Vue 3、TypeScript、Vite、Three.js 与 GSAP：Vue 负责界面，TypeScript 负责开发检查，Vite 负责开发与构建，Three.js 保留物件渲染能力，GSAP 用于动作与转场。未套用预设样式库。

当前场景主要使用生成底图与透明精灵。图片提示词、用途及来源记录保留在 `docs/art/` 和资产表中；部分声音、模型及旧素材仍是样本。第三方库的具体版本由 `package-lock.json` 锁定，许可证与最终交付说明需按实际使用范围继续整理。
